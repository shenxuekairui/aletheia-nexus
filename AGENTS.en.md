# Collaboration notes for Aletheia Nexus (溯光)

[中文](AGENTS.md)

- Focus on useful research materials and lasting reuse. Keep the project local-first, source-linked and open to researchers' checking and revision.
- Primary documents are Chinese with independent `.en.md` counterparts. The README introduces the whole project's purpose, capabilities and starting path; dedicated documents carry version details, scores and acceptance evidence. Retain both product names while preserving compatible commands, package names, URLs and schemas.
- Do not overstate scientific results. Separate errors, omissions, uncertainty and execution failures; preserve frozen evaluation rules and original evidence. Assistant review is not human confirmation or expert gold. Do not claim unexecuted checks or publication as completed.
- Protect user changes, original papers, canonical artifacts, raw answers and history. Save additions and revisions as traceable derivatives. Keep secrets out of source, ordinary logs and outputs.
- Reuse existing services and the smallest general mechanism. CLI, UI and MCP share one engine. Do not hardcode paper answers or add architecture without demonstrated value for individual examples.
- Develop incrementally and run relevant checks; content and link checks are sufficient for documentation-only edits. At release, run necessary engineering, compatibility, installation and actual-entrypoint validation and retain honest limits.
- Follow the user's current explicit authorization. Do not repeatedly request already granted development, budget, push, merge or publication permission, and do not expand it yourself. User instructions take precedence over these working suggestions; add no extra approval process.
