## 实现与验证边界

| 要求 | 已实现及真实验证 | 尚有限制 |
| --- | --- | --- |
| 审计并复用 v0.7 | 保留来源核验、parsed-document/v3、检索/证据包及导出；审计和决策见[设计](V08_DESIGN.md) | PARSED 仅是处理状态，不保证科学内容 |
| 真实模型 | 一个 DeepSeek Responses 适配器；实际文本、选页图像及结构输出；超时、有限重试、费用及错误分类 | 仅一个 Provider；视觉读法也会出错 |
| 通用任务 | JSON Task、自定义字段/类型/单位/阶段；organize/extract/procedure/compare 共用引擎 | 不含领域专用引擎，不自动推断可靠字段口径 |
| 可选过程输出 | include_steps=false 同时约束步骤及步骤引用；两个实际 API 任务验证 | 输出约束不验证实验条件含义 |
| 材料与补充 | 版本化包、选页/查询、块及原页图像、SI、备注、修订覆盖层；有限补页与旧结果保留 | 材料已提供也可能被模型遗漏；补充可能失败 |
| 实验整理 | 条件表、按顺序的步骤、原始值/单位、未报告/歧义/规范化的区分 | 真实结果仍出现合成、表征、性能测试条件串用 |
| 跨文献 | 字段统一导出与有来源的比较；8篇比较稿另经21次助手修订，10主张及10诊断复核 | 原始模型仍有过度概括；修订稿不是自动准确率提升 |
| 批量/恢复/缓存 | 单篇失败隔离、检查点、预算、兼容结果复用；实际失败后恢复及缓存零调用 | 顺序本地运行，没有复杂调度器 |
| 本地复用 | Markdown、字段table.csv、主张claims.csv、记录/主张 JSONL、任务、清单；报告标示缺席材料，保留字段范围 | 原始 AI 输出须核对，CSV 不制造失败占位记录 |
| 修订 | 记录、主张、诊断的历史版本；三个真实实例经 26 次助手修订后导出，均不可设人工确认 | 用户授权 GPT 评阅，未建立独立人类专家标准 |
| 三种输入 | local 零 AI；parsed、hybrid、direct 实际对照；direct 可用选定原页 | 整篇任意长度 PDF 一次直传不是本版能力 |
| 安全与兼容 | 明确启用远程；密钥来自环境变量；原 PDF/规范工件只读；预算与源哈希检查 | 本地资料及授权论文不进入公开仓库 |

模块职责：`processing/contracts.py` 定义任务/结构契约，`materials.py` 准备可追溯
材料，`provider.py` 调用模型并记录用量，`engine.py` 处理批量、补充和恢复，
`results.py` 校验来源、导出和修订，`processing_cli.py` 提供命令。
未引入数据库、向量库、模型路由或 Agent 框架。解析保护改动针对真实异常，兼容 v3
工件；详细原因、替代方案和验证见[设计](V08_DESIGN.md)与[验收记录](V08_ACCEPTANCE.md)。

## 三类科研任务的真实情况

较早的 20 篇实际执行：A 保存 19/20 篇，C 保存 20/20 篇；B 先验证两篇与比较。
这些是执行能力证据，不能据此声称准确率。随后冻结同一批十篇论文，执行 A/B/C
三类任务的 parsed/hybrid/direct 对照：每条路径预定 210 个字段及 20 个步骤检查、
40 条完整记录。三个路径不是三十篇独立论文。

| 冻结 v6 路径 | 复合字段查准率 | 查全率 | 完整记录正确率 |
| --- | --- | --- | --- |
| parsed | 80/139（57.6%） | 80/197（40.6%） | 2/40（5.0%） |
| hybrid | 47/83（56.6%） | 47/197（23.9%） | 3/40（7.5%） |
| direct | 65/184（35.3%） | 65/197（33.0%） | 1/40（2.5%） |

这是严格复合字段/完整记录口径，不是单个数字识别率。原评分和后来发现的参考勘误
均保留。GPT 原文评阅不是人类专家金标准，也不代表其他研究领域的性能。

后续 v7 开发回归复用这些论文，保存 A 8/10、B 8/10、C 7/10 篇和一个比较结果，
共 30 条记录。查准率 **76/143（53.1%）**、查全率 **76/197（38.6%）**、完整记录
**1/40（2.5%）**；54 个字段遗漏、9 个预定检查中的条件关联错误。另对全部实际输出
的 277 项进行评阅：非空断言原文支持 **247/268（92.2%）**，引用可定位 **268/268**。
后者不能替代前者；失败文献没有从预定分母剔除。该轮提前修正两个参考检查、收紧
完整性评阅，因此不得直接与旧分数相减来宣称提升。

v8 补充策略的小实验发现了真实收益和新错误，尚无全套同口径性能证据。字段拆分
实验固定 23 项检查，宽泛字段 10 项通过、拆分字段 9 项通过，未采用自动拆分方案。
不能把额外模型调用、步骤减少或引用校验通过当作科学质量提升。

进一步的三篇C类开发对照比较同时提取两阶段与单阶段任务：固定检查7/48与10/48，
但后者一篇退步、阶段关联错误增加。保存记录变多并不满足预定采用标准，未引入
自动阶段拆分；完整结果与失败见[验收记录](V08_ACCEPTANCE.md)。

随后只改变材料页码，三个选页任务均保存两条记录；同一组固定检查从7/48变为
25/48。但全部输出仍有7项条件/对象关联错误，未满足预定采用标准，因此没有加入
自动选页或修改默认路径。选页由已读过这些论文的GPT指定，不是独立留出验证。

之后仅换用保留字体边界的新解析工件，保持三篇任务与48项检查不变：25/48变为
26/48（逐篇10→9、8→9、7→8），复合字段21/38，完整记录仍为0/6。一篇退步，
不能声称已证明提取改善。全部76项输出另发现5项条件/对象关联错误、3项未报告的
静置操作，以及8项引用未完整覆盖复合表述的问题。原文中能找到某个值，与当前
引用足以支持整个表述仍有区别；该更细的引用复核未追溯重算旧结果，不直接比较
两轮支持率。保留解析修复的依据是结构与文本完整性验证。
