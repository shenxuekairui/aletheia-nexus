## 关键修复与架构

| 问题 | 最终处理 |
| --- | --- |
| 外文中文译名导致原身份验证不通过 | 使用同 DOI 登记元数据，或唯一 DOI 匹配的落地页元数据，补全原题名；仍执行原 `pdf_front_matter/v2`，不降低 DOI 冲突或补充材料门槛 |
| 结构化 DOI 本地导入误选知网策略 | 已知 DOI 的本地导入回到原校验器；无 DOI 的本地导入保留严格书目校验；原请求留在溯源中 |
| 获取成功被后续认证/失败覆盖 | 已开始的 CNKI 下载不进入通用重复下载路线，不在传输失败后盲选另一条目；晚完成认证的恢复保留原 `PaperRequest`、断点键和历史 |
| 同 DOI 不同约束互相覆盖 | JSON/CSV 的每条题名请求独立建模；断点键包含题名、作者、期刊、年卷期页与 CNKI ID；拒绝把小数年份截断或将作者字典误当作者列表 |
| 同 Cookie HTTP 与浏览器实际交付不同 | 默认原生点击 PDF 控件并捕获附件/响应；保留显式 `--cnki-context-request`；传输错误分类而非要求用户登录，不关闭 TLS 校验 |
| 知网广告 PDF 被误作正文候选 | 精确排除已观察到的 `a.cnki.net/gw/api/get/pdf/ads/`，不按泛化的 `pdf`/`ads` 字样排除其他来源 |
| 检索控件、篇名菜单或结果迟迟不就绪 | 下载前、无认证历史时仅允许有界恢复；篇名菜单纳入冷启动恢复，结果等待最多重试一次；下载已开始后不重放 |
| 无 DOI 详情题名已冲突但仍下载 | 将最终校验器已有的精确题名要求前置到详情筛选，提前跳过，避免消耗无效下载；已知 DOI 的中英文题名仍保留 DOI 优先路径 |
| 独立脚本与安装程序脱节 | 正式 `aletheia-nexus acquire` 支持结构化/无 DOI 输入、分流、非交互与交付方式；旧脚本为兼容入口；`browser-install` 打包进安装版 |
| 浏览器历史下载崩溃 | 保留受影响版本拦截与 AN 独立修复版运行时，Windows/Linux CI 均部署修复版；不删除历史、Cookie 或用户配置 |
| 中文 PDF 进入解析层崩溃 | 畸形引用范围如 `[10-12-11]` 不再触发整数转换异常；保留原文字，不生成猜测的引用链接 |

分层保持为：请求/分流 → Provider 选择与页面获取 → PDF 交付 → 共享 PDF 结构/身份/角色校验 →
CNKI 附加书目约束 → 原文件存储与 SHA-256 sidecar。知网页面得分、详情 DOI 或下载成功事件本身不能生成 VERIFIED。

`auto` 保留公开来源和官方 API 优先级；明确 CNKI 来源、文献 ID、DOI 家族或中文登记书目才进入 CNKI。
仅中文译名的弱线索不抢在原出版社浏览器路线之前。`exclude_cnki` 是 Provider 排除，不是 DOI 跳转的域名防火墙。
直连默认值、显式系统代理、认证边界以及原出版社恢复机制保持原获取层语义。

## 分轮现场证据

所有本轮运行均无人值守：复用已有 AN 配置，不输入密码、不操作验证码、不购买访问。
每轮使用新的输出目录，不用断点伪装成新下载。运行中加载的代码不会随磁盘修改自动更新，故明确区分批次。

### A. 集成 API 的 34 项诊断批次

含原 20 篇跨领域 CNKI、最早的 7 个 DOI、3 个标题用例、错误作者、宽泛同名探针和 2 个外文对照。
本轮仍使用 HTTP 优先交付，尚未加载后续原生默认值与禁止通用重复下载的修复：

- 28 `VERIFIED`，3 `INTERACTION_REQUIRED`，3 `EXHAUSTED`；首 20 篇为 19/20。
- 全部 28 个成功文件的结构和 SHA-256 独立复核通过；涉及 CNKI 的成功文件再按 v3 书目规则离线复核，无身份冲突。离线复核不计为新下载。
- 部分 CNKI HTTP 失败随后由通用路线取得文件，使用原 v2 校验；这些路径不能当作 CNKI v3 专属路线的成功率，已据此修复重复获取边界。
- CNKI-20 的首次 HTTP 失败被 DOAJ 的验证码终态覆盖；另两个认证条目为最早测试集 #1、#2。没有人工完成这些挑战。
- 无 DOI 标题首次为传输失败；错误作者未获 VERIFIED；宽泛题名探针为未获取，不能宣称它证明了真实同名歧义检测。

外文两个对照均真实新下载成功，均未使用 CNKI，均为 `pdf_front_matter/v2`：

| DOI | 校验题名来源 | 结果 |
| --- | --- | --- |
| `10.1038/s41467-024-49639-6` | DOI 登记英文题名 | VERIFIED |
| `10.1038/35104620` | 从中文译名恢复登记原题名 `Materials for fuel-cell technologies` | VERIFIED |

第二篇实际 PDF 没有可提取的目标 DOI，修复原题名后由原校验器的首页题名证据通过；不是通过登录状态、URL 或降低身份标准通过。

## 解析衔接

真实新下载的 CNKI-03、CNKI-20，以及标题检索后发现真实 DOI
`10.3969/j.issn.1006-3951.2025.06.009` 的文件，已通过正式 `parse` 入口生成 `PARSED`。
三份输出的锚点覆盖率为 100%；这仅验证流程衔接和来源锚点，不代表所有章节、表格或科学语义都被完美恢复。

无 DOI 获取、存储及校验已支持；现有 v0.7 `parse --doi` 仍要求真实 DOI。
本次不伪造 DOI、不放宽解析入口的证据要求，也不宣称无 DOI 文件已经接通全部下游解析功能。
