# Aletheia Nexus — 版本与验收记录

本文件保存历史版本、测试快照和真实网络验收口径；[README](../README.md)只负责介绍项目、当前能力和使用入口。以下数字各自属于**当时的提交、输入集与环境**，不是可直接横向比较的通用下载成功率。真实出版社结果会随机构授权、站点状态和运行预算变化。原始报告可能包含受保护的访问上下文，保留在本地而不提交仓库。

为保护原开发仓库的个人提交信息和旧运行记录，本公开仓库从审计后的 v0.6 源码快照开始，**不携带早期 Git 提交和 `v0.5.2` tag**。下文的 v0.5.2 数字是原私有开发仓库冻结时的历史记录，不应被理解为可以在本公开仓库检出的标签或提交。

## v0.6.1 — CLI、适配器与 Windows CI

本轮将出版社页面差异迁入 `publisher_adapters/`、通用下载捕获迁入 `browser_engine/`，提供安装后的 `aletheia-nexus` CLI、Windows CI、PyPI Trusted Publishing 以及英文/社区文档。历史 v0.6.0 的 **734 passed、7 skipped** 是旧提交的记录，不能自动当作 v0.6.1 的最终测试结果。v0.6.1 须在最终提交重新运行本地与云端测试，并在真正上传 PyPI 后从全新环境验证 `pip install aletheia-nexus`。具体发布门槛见[v0.6.1 开发与发布计划](v0.6.1-development.md)。

2026-09-24 开发快照（**不是**发布验收）：本地 Windows / Python 3.14 确定性测试 **742 passed、7 skipped**，真实 Chromium 集成 **7 passed**，Ruff、固定 20 篇输入完整性、sdist/wheel 构建和 `twine check` 通过；从独立临时环境安装开发版 wheel 后，CLI 版本与 `doctor` 检查通过。单篇公开 DOI `10.1371/journal.pone.0310216` 经新 CLI `--public-only` 得到 `VERIFIED`；这只是一个公开路径烟测，不是跨出版社成功率或机构授权阳性对照。开发提交 `a5e1023` 的四个云端 job 均实际通过；正式发布提交仍须重新核对。

项目发起者于 2026-09-24 决定先发布 v0.6.1，并在[发布说明](RELEASE_NOTES_v0.6.1.md)中明确披露：陌生用户的首次安装/三分钟体验尚无独立反馈，正式跨机构授权阳性对照仍未完成。两项都是发布后的开放验证工作，不能写成已通过。

## v0.6 — Acquisition Maximization（首个公开代码版）

v0.6 在公开 HTTP 获取无法获得 `VERIFIED` 主论文时，增加官方授权 API、持久浏览器会话、机构/账号认证和受控的人在回路恢复。PDF 仍须通过共享的结构、目标身份和正文角色验证。Nature/ACS 的可复现假阴性及“后页引用 DOI”假阳性促成了 `fulltext/identity.py` 与 `validation.py` 的定向回归修复；原私有仓库的 `v0.5.2` 标签未修改。

2026-09-23 的本地 RC 确定性测试快照：Python 3.11 与 3.14 各 **734 passed、7 skipped**；两个版本的 7 个真实 Chromium 集成用例均通过。`2026-09-24` 的后续文档/基准集检查在 Python 3.14 上再次得到 734 passed、7 skipped，Chromium 集成 7/7，Ruff、依赖、构建与工作流语法检查通过。本地结果本身不替代最终发布提交的完整云端 CI。

### 历史 40 篇压力集

2026-09-23 的同批次结果如下；分母包含燃料电池、CDI、海水淡化三组固定输入：

| 输入集 | 同批次 `VERIFIED` |
| --- | ---: |
| Fuel-cell classics | 14/20 |
| CDI | 9/10 |
| Seawater desalination | 8/10 |
| 合计 | **31/40** |

此后在相同 40 篇 DOI 范围内进行独立单篇复测：三篇 ScienceDirect 在用户完成合法机构认证后验证成功；两篇 Nature 正文在修正第一页标题提取边界后验证成功；IEEE 一篇在用户完成机构认证后，由 AN 自动取得并验证。因此**按 DOI 去重的累计结果为 37/40**，不是一次完整重跑的成功率，也不回填 31/40 的原始批次统计。

余下三篇：`10.1038/nchem.367`、`10.1038/s44221-024-00340-4` 的页面要求购买，为明确的订阅边界；`10.1061/(ASCE)0733-9372(2007)133:11(1004)` 的机构登录未完成，原始批次为 `INTERACTION_REQUIRED`，不能推断其最终订阅权限。已复现的 ACS 正文页“Supporting Information”导航误判、Nature 首页标题顺序误判均有回归修复；不能据此声称所有新出版社版式均无假阴性。

### 用户指定 20 篇输入

2026-09-23 的[原始真实输入集](../benchmarks/user_20260923_20_with_titles.json)只有 2 篇显式附带标题。经 AN 持久 Edge 会话、用户完成机构登录或验证码、检查点续跑和独立复测，按 DOI 去重累计 **19/20 `VERIFIED`**。最后一篇 `10.1055/a-2508-9744` 的官方正文入口要求购买，用户确认当前无订阅权限；该轮自动尝试中的 `EXHAUSTED` 不应写成 PDF 验证失败。

为分离“元数据解析变化”与“获取层变化”，仓库另存了同一 20 个 DOI、每篇都有固定标题/出版社/出版年的[冻结输入集](../benchmarks/user_20260923_20_frozen.json)。**19/20 是原始输入的历史累计结果，不能冒充冻结输入的一次新测试。**具体来源、字段规则和离线完整性检查见[基准集说明](../benchmarks/README.md)。
