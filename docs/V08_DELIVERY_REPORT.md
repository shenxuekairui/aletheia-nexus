## 实际功能与实现职责

| 模块 | 交付能力 |
| --- | --- |
| `research_app.py` | 受限目录内文献枚举、登记与准备，复用解析材料，任务校验、中文计划、预算、独立本机授权与后台状态 |
| `research_ask.py`、规划器 | 中文需求生成 `research-task/v1` 草案；仅元数据规划与论文内容执行分开授权、计费；保存、修改、确认或取消 |
| `mcp_server.py` | 官方 Python SDK v2 `MCPServer`、本地 stdio、23 个工具；复用应用接口，不建立第二套提取引擎 |
| `processing/contracts.py`、`engine.py`、`provider.py` | 自定义字段与步骤、真实 DeepSeek 文本/图像输入、结构化输出、有限重试、缓存、部分成功、费用与失败记录 |
| `materials.py`、原生表格及材料表达模块 | 任务材料包、上下文、表格、SI、原页及局部区域；派生补充和人工修订保留来源，不覆盖 PDF 或规范工件 |
| `source_first.py`、`readings.py` | 可选先读后组装、保留首读笔记；组装超输入预算时尝试已有可逆紧凑表达，复用成功首读 |
| `results.py` 与既有导出 | 引文定位与修订历史、Markdown/CSV/JSONL、本地历史读取与重新导出 |

四类通用任务共用字段和来源机制，没有材料合成专用引擎。MCP 覆盖 DOI 获取、题名候选、导入与 SI 绑定、文库筛选/标签、解析、检索/上下文/原页、科研任务、状态、结果、修订与导出。题名查询只返回至多五个候选，显式选择 DOI 后另行授权获取；机构登录与权限问题仍沿用既有人机协作入口。

远程默认关闭。MCP 只读用户允许目录和工作区；独立本机授权绑定任务指纹、范围与预算，模型传入 `confirmed=true` 不能替代批准。协议使用 stdout，日志使用 stderr。密钥只读取环境变量，不写入任务、报告或普通日志。没有新增数据库或常驻聊天 Agent。

## 路线取舍与已修复问题

- **逐字段独立读退役。** 新 8 篇相比正常路线少 7 个正确字段、5 条完整记录，0 篇净增、6 篇退化、2 篇持平。旧任务/结果仍可读取、校验、修订与导出；新执行明确拒绝已退役策略，不静默换策略或重新收费。配套短字段输出候选只保留离线证据，不留下无收益运行模块。
- **紧凑材料保留资源用途。** 相同 8 篇首读实际输入 Token 从 721,325 降为 626,876，减少 13.09%；原文、字段、约束与图片保持。科学上净少 1 字段、1 记录，不能宣传准确率升级。组装超字符预算时的可逆紧凑回退已实际恢复 CLI，仍超限则明确失败，不截断科学内容或擅自增预算。
- **同源逐字引文定位保留。** 只在已提供来源内、引文唯一且精确匹配时修复页码/块编号，保留前后值及依据。4 处真实定位零 API 恢复，科学值、原引文和待核对状态不变；旧缓存与原正式成绩不回填。
- **原页直读与局部图像读取保留实际读取用途。** 扩大对照未证明普遍替代混合路径；整页加固定局部图并未稳定改善读数。不全局强制切片，MCP 仍可按任务读取受限区域。
- **实验单元合并、额外复核、保留首读、简化 Schema、字体材料、模型阶段对照均已筛选。** 没有证明普适净收益的路径不设默认；`preserve_readings` 仅保留一次 AI 首读笔记的明确用途。只追加步骤关联扩大到 10 个 C 类任务、15 条记录后无适用缺口，未为零适用项重复调用模型。详细正负证据见[路线复验](V08_ROUTE_REVALIDATION.md)与[优化台账](V08_OPTIMIZATION_LEDGER.md)。
- **可靠交付修复。** JSON 收尾及可识别附加元数据处理避免整答丢失；Windows 状态读写竞争以短文件锁解决；来源与预算变化改变指纹，旧有效阶段可恢复复用。工程恢复不当作科学准确率提升。

剩余主要错误包括总量与组成混淆、载体/对象/实验阶段归属、把不同因素趋势合并，以及误把不同指标口径认定为矛盾或未报告。多数必要信息已经出现，简单增加思考、输出或复核未显示稳定收益。后续若有新领域材料或更强模型，应建立独立冻结对照，不能承诺现有严格分已达标。

从一个含中文文件名的真实原始 PDF 文件夹开始，用户目标为整理研究对象、方法、作者主要结果，生成中文笔记与 CSV。规划只发送目标和元数据，实际 1 次模型调用；保存的任务未经手写字段改造，由本机操作者按用户已有授权核对范围与指纹后执行，不伪称人工现场确认。

## 最简单的使用方法

Python >=3.11，在源码目录安装；需要 MCP 时添加可选依赖：

```powershell
pip install -e ".[mcp]"
$env:DEEPSEEK_API_KEY = [Environment]::GetEnvironmentVariable('DEEPSEEK_API_KEY', 'User')
aletheia-nexus research ask "整理这些论文的方法、实验条件、主要结果与局限，生成中文对比表并保留来源" --papers "F:\papers" --output-dir "F:\results\an08" --extraction-strategy source_first
```

先确认发送指令与元数据，再核对中文计划、范围和预算后执行。可保存、修改或取消。没有密钥时明确提示，不伪称理解需求。`--max-calls`、`--max-cost` 与 `--max-input-characters` 可显式设置预算；修改任务会生成新指纹，旧批准不能直接用于新预算。图像预览显示初始页面，混合模式可在同文献及既定预算内补充原页。

MCP 本地启动：

```powershell
aletheia-nexus mcp serve --allow-dir "F:\papers" --workspace "F:\results\an08"
```

可复制的 [Windows stdio 配置](../examples/mcp-stdio-windows.json)需替换 Python、论文及工作区路径。默认无远程模型许可；按[中文入口指南](V08_ENTRYPOINTS.md)配置远程环境和本机授权。密钥不写入客户端 JSON。删除客户端配置或停止 stdio 子进程即可禁用，不涉及公网服务。更多使用方法见[科研功能指南](V08_USER_GUIDE.md)。
