## 模型整理与出处

普通输入预览不发出模型请求。模型每次最多一次 HTTP 请求，失败不自动重发。
输入最多 50,000 字符 / 200,000 UTF-8 字节，默认输出上限 8,192 Token，可明确提高至 65,536。
这不是一万篇文献的单次模型处理承诺。

模型不能新增原文没有的 DOI。有 DOI 且没有其它书目字段的条目，由服务器原始 occurrence
确定出处，避免模型错误拼接行号。含标题、作者、年、刊的条目仍逐项核对其连续原文引用。
本地能确定的显式分类/标签以原文为准；模型遗漏或替换不覆盖原值，修正保留审计说明。
`DOI | 裸标题` 只在整理服务内用有界影子输入提取组织语法，原文、标题和科学身份校验不被改写。
未知的模型分类建议仍需人工确认。

两次真实失败均保留原 receipt 和已知用量，没有伪装成成功或零费用：一次引用跨非连续行，
一次模型把 100 条明确分组误写为根目录。修复后对原失败候选进行离线重验，再独立授权新版真实调用。
最终 v4 的五组并发实测全部通过：原 25 条四组清单、100 条真实 Crossref 书目、三组混合输入。
混合输入涵盖真实作者/年份、故意不提供 DOI 的标题、根目录、空标签、同行多个 DOI 和重复论文组织冲突。
草稿中保留的冲突不等同于已经解决冲突或下载成功。
