## 默认解析的修复

G02 p5 Table I 原页包含六列。现在 Ti/PVP-Pr-nanoTiO2 行保留为：草酸质量 5 g、电流密度 55 mA·cm−2、乙醛酸质量 4.13 g、电流效率 81.3%、产率 82.6%。另三种电极行的空单元格保持为空，不把后面的数值左移；正文的 81% 与表格的 81.3% 分别保留。

这次查明的根因是两条通用规则相互影响：页底整数被页码过滤规则删除；表题宽度略低于通栏阈值，使邻栏正文插入表题与单元格之间。上一轮关于“预合并数值”的推测不是本次确认的根因。

修复让已经识别的表格结构优先于页码过滤，并由实际网格确定表题所属阅读带，保持原表题的真实坐标框。没有按论文 DOI、名称、表号或答案数值改写文本。已分别用默认原生解析和原生加双 OCR 验证 G02。

逐页对比 68 份 PDF、587 页，旧版主读法的空白分词多重集没有词项丢失。只有四页增加文字，均回看原图：G02 p5；T0 P04 p4、p6；T0 P19 p8。P04 恢复了曾被页码规则删去的表格整数和零。P19 的文字恢复同时暴露了重复读法与列碎片，详见剩余限制。这个检查证明保留情况，不证明全文语义或坐标准确率。

## 减少固定样本假设

移除了三处固定数量限制：表头最多三行、换行单元格最多两项、只从最后八个片段推断换行位置。现在依据相邻完整数据行的列位置及实际间距判断。还修正了两个并排单栏表格被错误合成通栏表的问题。

新增 20 个表格场景覆盖 0.6/1.0/1.8 倍缩放、页底和页中位置、三种表题宽度、五行表头、十二列及并排表格。测试使用自行构造的数值，不读取私有文献答案。几何与字形约束仍保留；这些变体测试降低了对已见版式的依赖，并不能证明过拟合已全部消除。

## 留给 AI 的最小接口

公共 API 为 `EvidenceJudge`、`ReadingDecision`、`assess_reading`，详细调用方式见[解析契约](V07_PARSING_CONTRACT.md#optional-reading-assessment)。它复用现有证据包及复核位置：输入包含主读法、候选读法、原页坐标、来源哈希和表格单元格位置；输出为读法建议、未解决或弃权，并重建原文引用。

默认解析不调用该接口。调用者须明确提供判断器；接口没有附带真实模型、图片渲染或远端服务。未知引用、缺少理由的回答会报错，模型失败向调用者报告。判断结果是建议，不会修改规范文本、清除不确定性或自动统一原文冲突。当前验证使用本地测试判断器，只证明接口行为，不是 AI 判断准确率。
