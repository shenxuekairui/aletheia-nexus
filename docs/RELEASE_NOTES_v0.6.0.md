# Aletheia Nexus v0.6 — First Public Release

这是 AN 的首个公开源码版本，以 Apache-2.0 许可证发布。它把论文获取中的 DOI 标识、候选发现、有界下载、PDF 身份与正文角色验证、授权访问和来源记录组织成一条可组合的本地链路。目标是给未来的文献解析与科研知识系统提供可信输入，而不是把任何能打开的 PDF 都算成成功。

## 本版交付

- **Implemented：** DOI/元数据解析、开放全文候选发现、多路径公开 HTTP 获取、PDF 结构与目标论文/正文角色验证、安全边界和来源记录。
- **Experimental：** Elsevier 官方授权 API、持久浏览器中的合法机构/账号访问、人在回路中的登录/验证码恢复、批量断点续跑。这些能力已实现并经过本地与浏览器集成测试，但实际站点路径和用户权限仍会变化。
- **Planned：** 内容解析、证据化知识组织、工作流和科研 Agent；不属于 v0.6.0 已交付功能。

针对可复现缺陷，本版修复了 ACS/Nature 正文误判及“目标 DOI 只在后续参考页出现”可能造成的错误验证。`v0.5.2` 历史标签保持不变。

## 发布证据

- Python 3.11 / 3.14 的确定性测试，以及真实 Chromium 集成测试，必须在本版最终提交的 GitHub Actions 记录中分别显示 `success`；不能把 `skipped` 当作通过。
- 本地完整 RC 检查：Python 3.14 确定性套件 **734 passed、7 skipped**；访问层（包含真实 Chromium 用例）**204 passed**。Python 3.11 的同规模本地记录和 7 个 Chromium 用例也已在发布分支验证。
- 2026-09-24 的三篇开放获取 DOI 烟测分别来自 Springer、Frontiers、Elsevier，均由 AN 得到 `VERIFIED` 主论文。测试未使用机构凭据；它们证明有限真实网络路径可工作，**不能**证明需要订阅的文献可访问。
- 历史困难语料的 40 篇结果是一次同批次 **31/40**，其后独立复测后的按 DOI 去重累计 **37/40**；另一个用户原始 20 篇输入为累计 **19/20**。这些数字的环境、输入与口径见[版本与验收记录](RELEASE_HISTORY.md)，不是通用成功率，也不是冻结 20 篇新基准的一次完整重跑。

## 明确限制

正式机构授权阳性对照资格验收**尚未完成**。项目发起者决定先发布代码与测试已封板的公开版，再补做至少三个、覆盖两个访问体系的已知有权限阳性对照。因此本版不宣称任何机构、出版社或学科的访问覆盖率已获认证。出版社可能依据 IP、机构、Cookie 或站点变化重新要求登录或显示购买页；AN 不提供订阅、不绕过付费墙、不代答验证码。只有通过 PDF 结构、论文身份与正文角色验证的文件才会成为 `VERIFIED`。

安装与用法见 [README](../README.md) 和[中文使用说明书](USER_MANUAL.md)。请勿把登录 Cookie、浏览器配置、认证页面截图、带签名参数的原始 URL 或受版权保护的论文 PDF 提交到公开 issue。
