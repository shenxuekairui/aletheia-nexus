# 中文科研工作台视觉规范

本增量将产品名称、页面标题、内容和操作分成明确层级，同时保留科研工具需要的表格密度。
视觉变化不改变获取策略、文献身份、科研任务范围或费用授权。

## 参考与采用原则

- [Carbon 字体系统](https://www.carbondesignsystem.com/building-blocks/foundations/typography/type-sets)：
  按内容角色组织字号、字重和行距，帮助区分主次、阅读与操作。
- [Carbon 排版策略](https://www.carbondesignsystem.com/building-blocks/foundations/typography/style-strategies)：
  主页提供清晰的产品识别，业务页采用适合持续工作的紧凑排版。
- [Material 3 字体应用](https://m3.material.io/styles/typography/applying-type)：
  分开产品展示、页面标题、内容标题、正文和标签，避免所有信息使用同一种醒目程度。

将这些原则转为现有 NiceGUI 样式和组件，没有引入另一套前端框架、远程字体或装饰图片。

## 层级与布局

| 角色 | 桌面字号 | 用途 |
| --- | --- | --- |
| 顶栏品牌 | 28px，较窄窗口 26/24px | 产品识别；原来为 18px |
| 主页产品名 | 38–54px，随窗口变化 | 明确显示溯光（Aletheia Nexus） |
| 主页说明标题 | 20–25px | 产品定位，与名称区分 |
| 页面标题 | 28px | 获取、文库、检索、研究、成果 |
| 内容分区标题 | 21px | 步骤、列表与结果分区 |
| 正文与表格 | 15/14px | 连续阅读和密集资料 |
| 辅助元数据 | 12–14px | 状态说明、目录与提示 |

统一使用系统字体回退，中文支持 Noto Sans CJK SC、微软雅黑、苹方等本机可用字体。
字体可用性取决于运行浏览器的平台，不强制下载外部字体，也不分发受限系统字体。

顶栏、导航和内容区共享最大 1760px 的网格及同一左右边距；宽屏避免内容无限拉长。
导航与顶栏共同保留在页面顶部，阅读长结果时仍能切换业务页。
窗口缩小时品牌工具与导航允许重新排布，统计卡变为两列；表格横向滚动只发生在表格内部。
主页突出主操作，业务页保留普通密度；使用间距、细边框和轻阴影分组，而非给所有元素加醒目背景。

## 色彩与交互

深蓝用于品牌与基础文字，青绿用于主操作和当前导航；浅灰底与白色内容表面区分层级。
状态仍用文本和图标表达，不只依赖颜色。交互焦点有明确外框，装饰性图标不重复朗读。

静态色值组合按相对亮度公式计算：

| 前景 / 背景 | 对比值 |
| --- | ---: |
| 顶栏白字 / 深蓝 | 14.57 |
| 正文深色 / 白色 | 13.24 |
| 辅助文字 / 白色 | 5.14 |
| 主页说明文字 / 渐变终点色 | 5.57 |
| 当前导航文字 / 选中背景 | 5.65 |

这些是指定色值的计算结果，不是整套软件已经通过无障碍认证的声明；渐变、禁用状态、
用户表格配置和真实字体仍需在实际页面检查。减少动态效果的系统偏好会关闭卡片过渡。

## 与易用性一起验收

- 在 1280 与 1920 宽度核对字号、对齐、整体溢出和操作入口；另检查较窄窗口的重新排布。
- 主页、获取、文库、检索、AI 研究、成果及全局窗口使用同一套层级。
- 文库表格保留已保存的列、宽度、排序和选择行为。
- 环境诊断提供中文普通状态表，原始诊断留在专家区域；检测到依赖不等于机构权限或模型质量通过。
- 浏览器连接故障展示阶段和可执行恢复步骤，正文、SI、费用与科学确认状态分别表达。

实际截图、行为核对和最终提交的 CI 结果在后续收尾验收记录中按版本保存；
视觉效果不代替科研证据、来源身份与完整工作流的验证。
