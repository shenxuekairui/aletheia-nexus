# v0.7.3 — 科研读法、实验关系与局部复核

本版按负责人修订的实际设计目标完成科研收敛，定位为本地证据准备和
可追溯复核工具。原正确率、零漏报及最终减负百分比目标未达到；详细
结论见[验收记录](V073_ACCEPTANCE.md)和
[原方案及授权修订](V073_FINAL_PLAN.md)。正式发行提交、CI、安装验证及
包校验和以 [GitHub Release](https://github.com/shenxuekairui/aletheia-nexus/releases/tag/v0.7.3)
附件为准。完成这条发布链后结束 0.7 系列，不再安排常规 0.7.4 功能版本。

## 实际使用中的变化

- 表格中的两行名称可以依据字形位置归入同一实验行；明确重复的带撇号
  条目可保留共享单元格跨度。缺少依据的空白标签仍显示局部缺口，不能
  自动继承前一个实验的条件。短小图内 OCR 不再打断已经对齐的数值列。
  与单个可靠原生字形相交的局部标点 OCR 作为替代读法保留，避免成为
  额外条件单元格并破坏共享跨度；不更改表格分组规则或删除原 OCR。
- OCR 补充范围使用原生字形和单词位置，减少把清楚正文、表格列间空白
  误当成缺字的情况。图内识别保留整页分割上下文，仍读取原生文字间
  的真实图示标签。相同科学文本合并来源；单位大小写、符号、数字、
  化学标签和否定词差异不能因近似拼写而被判为一致。
- 短裁剪不能覆盖较完整的原生文字，也不能因数字相同就丢掉不等号、
  单位、百分号或脚注。图轴读数顺序冲突、同一标尺的单位读法冲突
  保留原读法和有位置的提示；提示不等于修复了错误答案。
- 同名字体的字形恢复现在按 PDF 字体资源分别处理，避免把另一字体的
  等号映射用于普通空格。重复排列且没有原生文字映射的矢量轮廓也会
  触发既有 OCR，并保留局部未核实提示；OCR 中相距很远的词组不再
  因同属一个识别行而拼成同一实验。完整历史回归已完成，第二封存集的
  首次完整判分也已完成，原数值目标未达到。
- 面板内的长度单位不再自动被称为标尺：保留简短的标签、位置和既有不确定性
  标记，避免把检测波长等文字包装成标尺。未增加通用标尺识别规则；
  原始读法及替代证据继续保留。
- 图中的无标题表格可依据真实横线、表头和重复数值列保留折行条件；
  具有重复指标名且唯一对齐的图内标签、数值和误差可保持在同一读法中，
  原始碎片保留为替代证据。编码缺字仅按 PDF 编码及实际嵌入字形恢复。
- 表题与数据之间有反应示意图时，明确的 Entry 表头和连续实验编号可
  确定下方数据行。图内同一标签下的多组百分比结果保留各自脚注标记，
  不自动认定它们使用相同实验条件；缺列和含糊位置不强行归并。
  分开排版的表号和标题也能进入这一流程；真实表头边线限制列宽，
  宽表头下的短条件值不再因距离中心较远而错归到实验编号列。
- 旋转图轴的指数依据实际字形位移与相邻关系保留为上标。嵌入字体中
  大写字形被错误映射为小写时，仅在编码与不同的字形轮廓共同支持下
  恢复大小写，并保留原映射；不会按化学词典修改标签。
- 检索补充观测到的表格行、表头、脚注、图注及有界相邻正文。重复 OCR
  命中后移，替代读法仍可查到。命中这些上下文不代表已证明它们属于
  同一个实验；旧查询和新科研查询分别计分。
- 知网详情页点击后若弹窗等待超时，只复用本次点击的新子页或已发生的
  同页跳转；无法确认时明确失败，不再通过重开同一 URL 隐式重试。
- 搜索与证据导出直接显示主读法、局部差异、缺失关系和页码。全部替代
  读法仍可展开并导出。显示折叠不计为消除了独立核对问题。

这次没有增加识别引擎、出版社覆盖、数据库或 Agent 框架。删除或收紧
的是已复现的错误融合和无效 OCR 范围；没有按 DOI、题名或指定实验值
加入专属替换。原始 PDF、获取证据和真实原文矛盾继续保留。

## AI4S 接入与兼容

继续使用既有 `EvidenceJudge` / `assess_reading` 接口。
[最小离线示例](../examples/assess_evidence.py)引用证据包中的文档及复核
位置，允许弃权，将建议独立保存并拒绝覆盖已有文件。示例不调用模型；
默认解析不上传论文、不调用远程 AI。AI 辅助成绩须与默认解析成绩分开。

格式仍为 `parsed-document/v3`，兼容读取 v2。证据包的主读法、替代读法、
局部差异等字段为兼容性增量；布局关系不被认证为实验数据。解析器为
`3.10.15`，原生版式后端为 `1.19.5`，自适应融合为 `1.10.5`，Tesseract
适配器为 `1.8.4`，图像 OCR 适配器为 `1.5.13`，分块导出为 `1.3.0`。执行身份变化会使批量
恢复重新解析受影响工件，避免静默复用旧结果。

## 验证与边界

当前完整结果记录于 [V073_ACCEPTANCE](V073_ACCEPTANCE.md)。第二封存集
16 份文件、673 页的四组执行与首次判分均已封存。主 OCR 配置默认完整
正确率从 25/60 提高到 35/60，无配对退步；错误数下降 28.6%，但低于
54/60 门槛，仍有 14 道题包含未被局部提示覆盖的关键问题。该组随后用于
修复判断，整体转为回归材料，首次成绩不变。限定表格补丁的暴露回归为
36/60、13 道题含未提示关键问题；这不是新的独立首次成绩，也不是最后
长度标签措辞调整后的全文件 OCR 重跑。最终证据保留检查确认这 36 道
完整答案不依赖已去掉的标尺断言，未额外增加分数。

最终缓存证据回放保留旧检索 Top1 13/32、Top5 24/32，SI 4/4，新查询
Top5 19/20。图中标签用途须查原页，二十任务补充台账的核对量为
42 到 33 次，中位数 2 到 0.5；原 25% 减负目标未达到。不再把较早阶段
的 21 次当作最终负担，也不宣称整库警告或人工核对量减少。
原 75 题当前严格完整为 70/75，包含两项去掉未经验证的标尺含义后需要
原页确认的题目；此前 72/75 保留为历史阶段。原确认的 52 项内容及
64 项历史关键回归继续保留。数值未丢失不等于实验解释已完整。

负责人在成绩已知后明确授权按实际设计目标收尾，不再以原数字目标作为
自动否决条件；原目标仍记录为未达到。当前定位是可追溯的本地科研证据
准备工具，关键数据引用和科学解释仍需原页复核。最终生产代码已通过
完整工程、干净安装和使用链路验证；正式发布沿用负责人最初明确授权，
最终发行身份与已发布包验证另列于 Release 附件。
开发回归、留出集首次成绩、原生解析和可选 OCR 成绩分别报告；测试通过、
安装成功或来源锚点齐全均不替代科研正确率。原 0.7.2 首次成绩保持原貌。

现有边界包括无法可靠读取的图版字母、缺少明确共享关系的表格标签、
模糊化学式、源文件损坏字形和复杂多阶段反应。局部提示使缺口可查，
不会把缺失答案变为正确答案。正文、表格与 SI 的真实矛盾分别保留。
`PARSED/PARTIAL` 不表示科学事实已经核实。样本成绩不能外推为全部文献
的总体准确率；助手复核的耗时不能当成人类使用者的效率实验。

## 安装与使用

正式 PyPI 发行版的安装命令：

```console
python -m pip install --upgrade "aletheia-nexus==0.7.3"
python -m pip install --upgrade "aletheia-nexus[image-ocr]==0.7.3"
aletheia-nexus parse PAPER.pdf --ocr --image-ocr rapidocr --ocr-languages chi_sim+eng
```

Python 3.11+；Poppler、Tesseract 和所需本地语言模型须另行安装。
不启用 OCR 的默认解析仍可直接使用，两个配置的覆盖边界分别说明。
操作入口见[使用说明](USER_MANUAL.md)、[科研工作流程](V072_RESEARCH_WORKFLOW.md)
和 [OCR 配置](V07_OCR.md)。Release 附件中的 `release-validation.json` 和
`SHA256SUMS.txt` 记录正式发布验证；开发候选包不能代替已发布发行包。
