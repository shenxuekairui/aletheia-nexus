## 实际使用中的变化

- 表格中的两行名称可以依据字形位置归入同一实验行；明确重复的带撇号
  条目可保留共享单元格跨度。缺少依据的空白标签仍显示局部缺口，不能
  自动继承前一个实验的条件。短小图内 OCR 不再打断已经对齐的数值列。
- OCR 补充范围使用原生字形和单词位置，减少把清楚正文、表格列间空白
  误当成缺字的情况。图内识别保留整页分割上下文，仍读取原生文字间
  的真实图示标签。相同科学文本合并来源；单位大小写、符号、数字、
  化学标签和否定词差异不能因近似拼写而被判为一致。
- 短裁剪不能覆盖较完整的原生文字，也不能因数字相同就丢掉不等号、
  单位、百分号或脚注。图轴读数顺序冲突、同一标尺的单位读法冲突
  保留原读法和有位置的提示；提示不等于修复了错误答案。
- 检索补充观测到的表格行、表头、脚注、图注及有界相邻正文。重复 OCR
  命中后移，替代读法仍可查到。命中这些上下文不代表已证明它们属于
  同一个实验；旧查询和新科研查询分别计分。
- 搜索与证据导出直接显示主读法、局部差异、缺失关系和页码。全部替代
  读法仍可展开并导出。显示折叠不计为消除了独立核对问题。

这次没有增加识别引擎、出版社覆盖、数据库或 Agent 框架。删除或收紧
的是已复现的错误融合和无效 OCR 范围；没有按 DOI、题名或指定实验值
加入专属替换。原始 PDF、获取证据和真实原文矛盾继续保留。

## AI4S 接入与兼容

继续使用既有 `EvidenceJudge` / `assess_reading` 接口。
[最小离线示例](../examples/assess_evidence.py)引用证据包中的文档及复核
位置，允许弃权，将建议独立保存并拒绝覆盖已有文件。示例不调用模型；
默认解析不上传论文、不调用远程 AI。AI 辅助成绩须与默认解析成绩分开。

格式仍为 `parsed-document/v3`，兼容读取 v2。证据包的主读法、替代读法、
局部差异等字段为兼容性增量；布局关系不被认证为实验数据。解析器为
`3.9.1`，原生版式后端为 `1.17.0`，自适应融合为 `1.9.5`，Tesseract
适配器为 `1.7.2`，图像 OCR 适配器为 `1.5.3`。执行身份变化会使批量
恢复重新解析受影响工件，避免静默复用旧结果。

## 验证与边界

完整结果将在科研验收结束后记录于 [V073_ACCEPTANCE](V073_ACCEPTANCE.md)。
开发回归、留出集首次成绩、原生解析和可选 OCR 成绩分别报告；测试通过、
安装成功或来源锚点齐全均不替代科研正确率。原 0.7.2 首次成绩保持原貌。

现有边界包括无法可靠读取的图版字母、缺少明确共享关系的表格标签、
模糊化学式、源文件损坏字形和复杂多阶段反应。局部提示使缺口可查，
不会把缺失答案变为正确答案。正文、表格与 SI 的真实矛盾分别保留。
`PARSED/PARTIAL` 不表示科学事实已经核实。样本成绩不能外推为全部文献
的总体准确率；助手复核的耗时不能当成人类使用者的效率实验。

## 安装与使用

以下命令在正式完成 PyPI 发布后可用：

```console
python -m pip install --upgrade "aletheia-nexus==0.7.3"
python -m pip install --upgrade "aletheia-nexus[image-ocr]==0.7.3"
aletheia-nexus parse PAPER.pdf --ocr --image-ocr rapidocr --ocr-languages chi_sim+eng
```

Python 3.11+；Poppler、Tesseract 和所需本地语言模型须另行安装。
不启用 OCR 的默认解析仍可直接使用，两个配置的覆盖边界分别说明。
操作入口见[使用说明](USER_MANUAL.md)、[科研工作流程](V072_RESEARCH_WORKFLOW.md)
和 [OCR 配置](V07_OCR.md)。最终提交、完整 CI、发行包及校验和在正式发布
验证完成后记录，不能以开发候选包代替已发布发行包。
