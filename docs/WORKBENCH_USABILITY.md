# 工作台易用性改进与验收（2026-10-28）

这轮以“首次接触也能在十分钟内完成一次基本操作”为目标，检查并改进输入、分类、标签、导入、
解析、检索和研究入口。默认流程不要求先制作 CSV、输入 JSON 路径或理解模型底层参数。
本轮没有调用远程模型，没有启动用户提供的 25 篇论文下载。

## 一批论文，各自保存

直接粘贴原来的格式即可，例如：

```text
A. TiO₂ 纳米管直接羧酸电还原
1. 10.1002/slct.202402850
2. 10.1016/j.elecom.2022.107204 | 标签=草酸,待读
B. 阴极活化、Ti³⁺ 与氧空位
1. 10.3390/nano13050931 | 分类=已有分类/待精读 | 标签=氧空位
```

点击“规范化与预览”后，分组标题成为分类，编号不再成为论文标题。分组标签、每行分类和标签
都有明确语法；它们由用户指定，不调用 AI 判读论文。中英文标题、纯 DOI、CSV/JSON 继续可用。

在预览表中：

- 选择一组或几行，一次追加、移除、替换标签，或指定目录。
- “选已有 / 新建目录”打开文库目录树；选一个已有目录，或在其下新建子目录。
- 双击目录或标签，只改这一篇；DOI 和标题仍可直接编辑。
- “获取状态”与编辑选择分开。“启用 / 停用”决定哪些论文进入本批；选择复选框只确定编辑范围。
- 可以跟随本批默认值，也可以明确保存到文库根目录、明确无标签。清空不会被默认值重新填回。
- 表中直接显示已有目录、下载时新建或需修正；“查看完整保存安排”可逐篇核对目录、标签和对应 SI/。
- 单篇文件基础名仍可在“逐篇命名与诊断（高级）”开启对应列后编辑。

输入及已提交的逐篇编辑自动保存在当前工作区的本地草稿中。切页、刷新、重启后可继续，
不会自动下载。开始新的一批可点击“清空本批”；如果修改了原始输入，需重新预览。
普通批量编辑完成后操作面板回到“保持”，防止上一组的目录或标签意外套给下一组。

正文继续位于各自分类根目录，同一分类的附件共享唯一 `SI/`。新输入和目录选择不替代
既有来源核验，也不修改旧 PDF、来源证据或科研任务。

## 其它流程同步修复

| 原来的操作成本 | 现在的行为 |
| --- | --- |
| 空文库主页全零指标、入口多，不知道从哪开始 | “十分钟开始”三步入口；可直接导入本地 PDF 或只填入公开论文示例 |
| 导入首先看见绝对路径、递归等参数 | 选择/拖入 PDF 是主入口；已有 AN 来源或目录导入放在折叠区 |
| 勾选论文后还要加入全局清单，再打开清单才能解析 | 直接“解析已勾选”“检索已勾选”，范围自动带过去 |
| 刷新、编辑表格后丢勾选、列宽或分组筛选 | 通过数据行 API 更新，避免界面组件隐式重建表格 |
| 标题查询期间编辑的目录/标签可能被候选结果覆盖 | 只更新目标行的书目身份，保留最新的逐篇设置和其它行编辑 |
| 搜索框按 Enter 无响应，切入检索后还要重复选范围 | Enter 可检索，文库勾选范围直接带入；切页返回保留查询文字和范围 |
| 检索命中开始研究会混入旧选择清单中的其它论文 | “仅用选中论文开始研究”明确采用本次范围，加入清单仍是独立操作 |
| 尚未选择材料就展示模型、预算和授权表单 | AI 页先引导选择材料；有材料后才显示相应表单 |
| 未启用翻译仍显示费用、授权与高级参数 | 仅启用翻译时展开相关控件，默认不产生付费请求 |

专业参数、原文核验、文件防覆盖及本次付费授权继续保留；减少重复操作和无关展示，
不通过放宽来源标准、静默覆盖文件或默认外发材料来缩短流程。

## 真实浏览器验收

本机证据目录：`F:/AI4S/outputs/AN08_workbench_20261028/usability/`。

1. **25 篇原始分组文本**：直接粘贴用户给出的 A–D 清单，准确得到 4、7、8、6 篇，无分组标题假论文。
   真实界面为四篇批量指定目录、追加标签，再将其中一篇设为独立子目录和标签；其它 21 篇未改。
   重新加载后全部 25 篇安排恢复，最终请求构建验证通过；`25-paper-arrangement.json` 保留逐篇参数。
   没有启动这 25 篇下载，没有联网确认它们的书目身份或科学分类。
2. **已有与新建目录**：在目录树中创建并重复选用空的分类，另在其下新建子目录，准确回填单篇设置。
   保存预览区分已有目录和下载时新建，并按分类显示统一 SI/。高级文件名列可实际打开。
3. **首次基本路径**：从零论文文库上传一篇真实的 8 页论文 PDF（DOI `10.1038/s41467-019-11903-5`），
   直接勾选解析，保持勾选刷新，再按本篇范围用 Enter 检索 `formate`，得到 23 条证据，打开第 8 页并实际载入原页图像。
   从主页截图保存到核验原页约 **328 秒（5 分 28 秒）**，包含一次浏览器自动化文件选择接口的超时和排查。
   未填写应用中的文件路径、未调整解析参数、未调用模型。

首次演练是代理操作真实浏览器，**不是招募未接触软件的真人完成的可用性研究**，不能保证每个人或
所有操作系统都在十分钟内完成安装、OCR 配置、机构登录及科研分析。安装就绪、已有普通 PDF 的
基本路径已跑通；扫描件、站点权限、网络和模型等待有独立前提。

上传单个 PDF 不携带其旁置来源 JSON，因此该次副本正确保留“本地声明身份”，没有冒称 VERIFIED。
解析为 PARTIAL，覆盖全部 8 页且保留警告。关键词命中、原页载入和科学结论正确仍是独立维度。
