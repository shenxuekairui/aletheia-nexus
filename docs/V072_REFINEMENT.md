## 实际改动

- **重复冲突只保留一份读法。** 相同文字、相同数字分段且空间位置高度一致的替代候选合并，来源模型合并记录，不清除不确定标记。不同位置、不同数字／单位仍分别保留。
- **数字分段不能被空格规范化吞掉。** `1 2` 与 `12`、`1.5 2` 与 `1.52` 不再被当作同一表达；`12 mA` 与 `12mA` 仍可比较。
- **CFF 和不完整 ToUnicode。** 对 Type 1C 嵌入字形及部分缺失 Unicode 映射，检查实际轮廓恢复明确的负号／短横线；有效 Unicode 映射优先，不按字体名或文献答案改字。恢复项保留不确定标记。
- **用保留的原生字形约束 OCR 主读法。** 原生乱码仍可能保留每个缺失字符的位置。另一完整 OCR 读法若匹配所有存活文字和缺失字符数量，而当前 OCR 主读法不匹配，则优先展示更完整的读法；至少保留 8 个可读字母／数字作为约束，并要求相应位置和置信度条件。它不填入未知数值，不在两个都匹配的候选间猜测，原读法仍保留。

最后一项将 P20 第 1 页的试剂纯度 `9.4%`、铅板纯度 `9.9色`，恢复为来源明确的 `99.4%`、`99.9%以上` 主读法。它们来自已有第二模型，不是写死到解析器中的答案。CFF 恢复同时修复 P07 的 `−0.50 V`、`−0.10 V`、`70 mA cm−2` 等表达中的缺失负号。
