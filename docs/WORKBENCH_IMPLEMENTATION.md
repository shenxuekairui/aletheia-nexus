## 纵向实施顺序

1. 先建立后台任务、设置与工作区、最小 NiceGUI 启动入口。
2. 导入/可信获取 → 分类根目录正文 → 同分类唯一 SI/ → 文库可见 → PDF 打开。
3. 标签/集合/筛选/持久选择 → 独立标题翻译 → 主文和附件预览、真实改名/迁移。
4. 选择 → 版本化解析 → 分页关键词证据检索 → 固定研究输入 → 编辑任务计划和预算。
5. 研究执行/中断记录 → 结果/PDF 联动 → 人工修订新版本 → 导出与历史复用。
6. 本地安装、浏览器纵向验收、核心回归、支持矩阵与用户手册。

并行职责：获取/SI、文库/文件事务、UI/科研桥接各一名子智能体；主智能体负责
任务、设置、翻译、入口、安全、交叉审查与整体验收。各自文件边界清晰，逻辑提交。

## 必须处理的工程风险

- **来源与路径**：逻辑 ID 绑定 PDF 和来源哈希，不使用文件名、DOI 单独作唯一身份。
  原 PDF、来源 sidecar、旧 parsed 和科研结果字节不变；新科研输入先复制到稳定快照。
  旧契约/检查点不能安全定位时阻止整理，并解释原因。诊断展示路径与权威输入引用区分。
- **分类 SI**：主文在分类根部，附件仅在该分类共享 SI/；根据父身份关联，逐文件移动，
  从不搬走整个 SI 目录。主文与附件共用消歧后的命名基础。
- **文件事务**：完整预检查、大小写/Windows 字符/路径冲突、哈希复核、分步日志；
  预览后文件变化需重新预览，失败不静默覆盖，回滚也需核验内容。
- **收费与中断**：调用前持久化预算预留；超时/未知用量不能记作零费用。进程重启标记
  INTERRUPTED，绝不自动重发。继续科研任务须重新审阅范围及授权。
- **真实任务控制**：PAUSE_REQUESTED 不等于 PAUSED，CANCEL_REQUESTED 不等于
  已停止。同步浏览器/HTTP/OCR 请求需到达边界后控制，UI 明示等待语义。
- **并发**：获取/解析/科研读材料与物理整理共享调度锁；翻译可独立运行。后台任务
  与浏览器页面生命周期分开，刷新/关闭页面不取消工作。
- **本机安全**：Host 和 Origin 对 HTTP/WebSocket 同时检查；只按随机能力 token
  提供明确选中的文件，不挂载整个目录；路径和文件身份每次核验，私有授权目录不可下载。
- **翻译**：原题、译名、显示名、真实文件名分别保存；保护人工译名；缓存包含标题、语言、
  模型和策略。只发送标题，不默认产生 API 请求，模型输出按稳定 ID 校验。

## 暂缓与高价值优化

暂缓语义数据库、通用 Agent、ELN、多用户云服务、完整 PDF 注释系统；当前关键词、
来源页及结构化任务已能完成主要流程，尚无引入这些系统的依赖。
精确坐标文字高亮暂缓，先交付可靠物理页和区域图像。
所有出版社 SI 的无条件支持不现实，优先明确官方链接与可核对父 DOI 的支持范围。

新增低风险优化：本机跨站请求防护、材料任务串行锁、保留计费不确定性、自动缓存保护
人工译名、区分当前页与全部筛选结果。这些分别解决实际安全、并发及误操作问题。

完成状态、实测数字与限制以 WORKBENCH_ACCEPTANCE.md 为准；本文件是实施决策，
不把计划或控件存在视为已经通过验收。UI 可用不代表科学抽取达到 v0.8 科学质量门槛。
