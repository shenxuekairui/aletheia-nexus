已知原文问题及 OCR 局限保留在逐题核对备注中：P01 的原文电流密度单位存疑；P15 的原生负号乱码与 OCR 读法分别保留；P19 中英文摘要的 80.90% 与 80.85% 冲突不合并；P20 扫描页的单位和百分号仍需看原页。扫描页能够打开和数字能够找到，不等于该项数值恢复准确。

## 实际工作流

| 场景 | 验收行为 |
| --- | --- |
| W01 输入 | 22 份 PDF 可进入文库；两篇无 DOI；实际历史 PDF 本地登记为 DECLARED |
| W02 SI | 两份 SI 保持父文献关联；导出使用 SI 自身实际 PDF 页码 |
| W03 查询 | 中文连续字符、AND、OR 与不存在词的负向对照 |
| W04 重复和短语 | 相同文件不增加命中，精确短语可用；同 DOI 不同版本由回归测试补充覆盖 |
| W05 选取导出 | 8 组实际选择带上指定条件页、角色、父文献、文件哈希和原页锚点 |
| W06 覆盖 | PARTIAL、未解析文件和未覆盖原因可见；零命中不声称全文没有相关内容 |
| W07 恢复 | 首篇完成后进程内 KeyboardInterrupt；再次运行复用首篇并继续待处理项。未模拟断电 |
| W08 迁移 | 正文和 SI 目录移动后仍可用；替换 PDF 或改变角色会被排除；v2 兼容另由回归测试覆盖 |

整库导出为带清单的 JSONL；逐题导出同时提供 JSON 与 Markdown。每项均含原始文件、实际 PDF 页码、解析状态、已知遗漏和内容锚点。材料只保存到本地。

## 0.7.3 收尾边界

仅处理实际使用复现的解析质量错误、恢复与稳定性问题、影响工作流的性能瓶颈、系统和 Python 兼容性，以及操作文档和发行打包。每项修复带复现材料或针对性回归；已有数值或来源误导问题不能以“留给 0.7.3”绕过本版验收。

不增加语义检索、向量库、自动实验数据抽取、自动综述、GUI、独立 PDF 阅读器、MCP 或对象模型重构。完成上述收尾后结束 0.7 系列，不再拆出新的功能小版本。
