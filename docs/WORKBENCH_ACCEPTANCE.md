## 复现方式

在源码根目录安装可选界面依赖和开发工具后，普通离线检查可运行：

```powershell
python -m pip install -e ".[ui,dev]"
python -m pytest tests/workbench -q
python scripts/verify_workbench.py --output "F:\AN验收\新的离线目录"
```

脚本要求输出目录尚不存在，避免覆盖旧验收材料。脚本内置生成合成 PDF，无需使用私人文库。
不添加远程开关时不会调用模型。只有用户另行确认当前费用、密钥、材料范围后，才使用
`--remote-titles` 或 `--remote-research`；普通 CI 不启用它们。

已经保存模型结果、仅在本地交付阶段失败时，可以显式恢复本地交付：

```powershell
python scripts/verify_workbench.py --output "F:\AN验收\已有结果目录" --resume-delivery
```

该恢复入口只读取已有结果，不调用模型。若尚无已保存结果或尚未到达对应交付边界，会拒绝恢复，
不能用它隐式重发模型请求。真实网络来源随时间可能变化；公开 DOI 实测成功不保证今后所有来源都可访问。

| 本轮不建设 | 向量数据库、完整语义知识库、通用 Agent、多用户云、ELN、完整 PDF 注释/精确文字高亮 |
