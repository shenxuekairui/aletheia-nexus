## 本次实际修复

1. 独立数字词项不再按子串命中其他数值。无符号查询按幅值匹配，显式正负号严格匹配；原文保持不变。补充范围、科学计数法、全角与精度不同等 21 个查询案例。
2. 修复双栏侧边信息抢占小字上标、上下标交错的问题。T0 的 V028 原先丢失速率单位中的负指数，现在可完整读取。后端版本从 1.1.0 提升到 1.2.0，避免继续复用旧解析结果。
3. 导出明确披露表格尚未解释、上下文缺块及图内文字尚未验证；不确定性随证据传递。未选择和预算跳过的文档均列入清单。
4. 角色／章节筛选报告实际检索范围；读取 v3 工件时核对题名、文献 ID 和身份来源，减少错误归属。
5. 分离“数值存在”与“完整表达可恢复”，补充排名、原文一致性、条件页、覆盖、预算与耗时的可复现评估脚本。

## 样本与口径

固定 T0：20 篇论文、22 份 PDF（含 2 份 SI）、184 页、22 个预先指定查询、69 项参考转录、8 项工作流。修复前后使用相同 PDF、题录、查询及参考答案，没有改写样本以提高成绩。新解析结果含 5,733 个块、655,758 个文本字符；9 份 PARSED，13 份 PARTIAL，0 份 FAILED。

当前评估使用 Windows 11、Python 3.14。真实 PDF、逐项数值及运行报告保存在外部工作目录；仓库只保存程序、方法和自编回归用例。

## 速度与可复用性

本轮结果是同一台机器上的同步墙钟时间，未清空操作系统缓存，不声称冷启动、大规模文库或跨平台基准。

| 操作 | 样本量 | 中位数 | P95 / 单次总计 |

| 重新加载文库、校验来源并完成首个查询 | 3 次 | 1.034 秒 | P95 1.156 秒（3 次中最大值） |
| 已加载文库的查询 | 22 题 × 3 次 | 0.138 秒 | P95 0.160 秒 |

P95 用 nearest-rank 计算，原始耗时写入 JSON。以上用于定位当前使用成本，不设置没有实测依据的大规模性能承诺。

## 回归与复现

完整默认测试：1,623 passed、113 skipped（本次新增 34 项）；真实 Poppler + Tesseract OCR 另启用后 1 passed。Ruff、编译、冻结获取基准通过；自编解析夹具 32/32 块有锚点、886 字符的错误率为 0，这不能外推真实论文的字符准确率。

前轮浏览器 81 项、CNKI 与可见浏览器 21 项回归通过；本次未改获取代码，未重复运行。默认跳过项及未验证平台的范围见 [验收记录](V072_ACCEPTANCE.md)。

量化脚本只评估可程序检验的指标；完整数值表达须另作逐项原文复核。后续修复至少保持相同 T0 的 Hit@5 为 22/22、来源／原文／条件页／不确定标记和预算检查全通过、完整表达不低于 65/69，并显式记录仍未恢复的项目。不能用任意加权总分抵消来源错误或未披露的数值损坏。

当前证据支持把 0.7.2 用于本地科研证据检索与带来源的 AI 材料准备；需要回查图表和不确定读法。未评估无人复核的结构化实验数据生产，也未完成 Linux、macOS 或其他 Python 版本的本轮实测。
