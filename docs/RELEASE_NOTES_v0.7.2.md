# v0.7.2 — 从论文到可回查的科研证据

本版本把文献获取、本地整理、解析、检索和证据导出连接为日常科研流程。验收重点是关键数值、单位、指标、实验条件及其原文出处；完整复刻 PDF、自动理解所有结构式和反应路线不属于本版目标。

## 实际使用中的变化

- **输入更完整：** 支持无 DOI 文献、本地 PDF 登记及关联正文的 PDF SI；本地声明与自动核验明确区分，SI 保留自己的页码。
- **证据可选择：** 跨文献 AND/OR/短语检索，按结果编号选择命中，展开实验条件页，导出 Markdown、JSON、JSONL 或结构化分块，并回查原 PDF。
- **解析更可靠：** 从字形和位置恢复负号、单位上下标、微单位和度符号；改善中文混排、多层表头、共享条件、相邻表格、印刷网格及表题之间的反应示意图处理。不同读法和真实源文冲突继续留存。
- **图内文字可补充：** 可选本地 RapidOCR 读取原图印刷文字、标尺和标签，记录模型身份与原图位置；不上传论文、不按化学常识补实验值。图内读法仍需按研究问题核对。
- **批量使用一致：** 单篇与批量解析共用配置，均支持模型目录、DPI、像素预算和段落合并控制；批次逐篇保存、验证后续跑。
- **获取流程修复：** 浏览器默认跟随系统代理，登录/验证码后恢复和原生 PDF 下载更可靠；知网默认文献间隔为 5 秒，明确限流后停止该会话后续知网请求。获取记录、检查点及标签默认收纳到 `json/`，兼容旧目录。

## 架构收尾

按项目哲学只整理已经出现的职责和重复：图表处理从主解析器分离；两种解析命令共享配置；HTTP 与浏览器获取共用身份/角色判定。保留普通 Python 函数、本地文件和现有有限接口，没有新增数据库、Agent 框架或模型服务要求。

重构使用已捕获的真实版式输入回放 **42 份、403 页**，完整解析文档保持一致（仅排除可迁移的文件定位路径）。这是行为等价性检查，不是新的 OCR 盲测。解析器仍为 `3.8.2`，自适应融合为 `1.8.1`，数据格式为 `parsed-document/v3`，继续兼容读取 v2。

模糊化学式中的 `l/I`、复杂多阶段反应条件以及正文与图表自身的矛盾，仍需查看对应原页。`PARSED/PARTIAL` 不等于科学事实已核实。真实出版社获取受合法权限和站点状态影响；本地浏览器夹具通过不代表正式机构授权资格验收已完成。

## 安装与升级

在 PyPI 完成上传后，可使用：

```bash
python -m pip install --upgrade "aletheia-nexus==0.7.2"
# 可选：本地图内 OCR
python -m pip install --upgrade "aletheia-nexus[image-ocr]==0.7.2"
aletheia-nexus parse PAPER.pdf --ocr --image-ocr rapidocr
```

也可直接安装本次 GitHub Release 附带的 wheel。整页 OCR 需要另行安装 Poppler、Tesseract 和所需语言模型，浏览器依赖仍为可选。模型版本、哈希及配置影响批量复用；旧解析工件会按需重新解析，原 PDF 与获取证据不改写。

具体操作见[使用说明](USER_MANUAL.md)、[科研工作流程](V072_RESEARCH_WORKFLOW.md)和[OCR 配置](V07_OCR.md)。最终发布提交的完整云端验证以 [GitHub Actions](https://github.com/shenxuekairui/aletheia-nexus/actions) 和 Release 附带记录为准。

0.7.3 的范围仍限于实际科研使用中影响结果的缺陷、安装/文档一致性和已有 AI 判断接口的接入说明。
