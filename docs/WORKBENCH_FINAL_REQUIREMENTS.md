## 判定与证据规则

- **已实现且实测**：入口真实调用应用服务，并有行为证据；下表明确区分真实 GUI、真实外部来源、本地夹具和确定性回归。
- **实现未验**：已有真实行为及测试，但要求的特定平台、权限、规模或人工操作尚无实际记录。
- **部分**：只交付了要求的一部分，列出仍需专家 JSON、额外人工步骤或尚未满足的性能目标。
- **缺失**：没有相应行为或入口，不能用底层接口存在代替图形化交付。
- **允许延期**：原始需求明确允许延后，或明确超出本轮范围；不把必需闭环操作挪到此类。

“实测”不表示科学抽取准确率合格。代理操作浏览器也不等于招募新手真人的可用性研究。
真实访问被阻止、附件待人工验证、材料不足和部分科研结果均保持原状态。

## 新手操作与剩余验收动作

当前无需返回终端或填写工件 JSON 路径的主链为：上传/粘贴 → 预览目录与标签 → 获取/导入 →
文库勾选直接解析/检索 → 命中选择直接研究 → 生成/编辑固定计划 → 本次预算与授权 →
任务进度 → 结果引用原页 → 修订新版本 → 导出。收藏范围可保存集合，下次复用稳定成员。
获取草稿与当前任务刷新恢复已有真实记录；临时科研表单尚未提交的修改不承诺跨整页重载保存。

后续验收必须明确执行及保留结果，而不是仅更新此表的状态：

1. **零收费 UI 回归**：同一已返回关键词报告切两种视图，确认范围/offset 不变、旧勾选清空、重新勾选后论文正确；切去文库再回检索，核对全部条件；失效集合不能扩大为全库。
2. **规划去重**：用确定性规划 stub 在浏览器双击，确认一个活动 job；失败后可明确重试，预算/目标改变可产生新任务。无需重复真实收费请求来验证这个保护。
3. **步骤引用**：用已有合法带步骤的本地结果，点“核对步骤”，验证 source ID/物理页；无 citation 的步骤只能显示说明，不能凭描述猜页。
4. **最终交付对齐**：主线待各业务收尾后跑完整回归、检查远程 CI 的具体 SHA，重建本地 wheel 并核对实际源码/哈希和仓库外启动；旧 `7941771` fresh 安装记录保留为阶段记录。
5. **权限待办**：RSC/Wiley/Elsevier 等保留当前来源、附件和浏览器诊断，由人完成合法登录或验证后按受支持边界继续；未经该动作不将其改为通过。科学抽取质量继续单独评估。

本表没有新增模型请求、读取认证值、改写生产设置或操控用户浏览器；不以人工待办、受阻站点和结构化格式通过冒充科学质量或全部外部平台通过。
