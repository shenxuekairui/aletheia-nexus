## 研究者可以做什么

- **本地工作台**：选择原始PDF或已有文库，获取、导入、分类与标签、正文/SI管理、预览改名和迁移、解析、检索、科研任务及结果共用本地服务。支持任务进度、部分完成和可恢复历史。
- **自然语言科研入口**：使用中文描述阅读目标、字段与输出，先产生可修改的任务计划，再按范围及预算确认执行。规划发送必要元数据，提取才读取论文内容，两者独立授权和计费。
- **科研资料交付**：单篇/多篇笔记、自定义字段表、实验条件与步骤、问题证据比较，保存Markdown、CSV、JSONL、来源、原响应及修订。结果可重读、核对和重新导出，不只存在于一次会话。
- **本地MCP**：官方Python SDK v2、本地stdio、23个工具，覆盖文献获取与准备、解析、检索/上下文/原页、科研任务、历史与结果；复用同一科研引擎。
- **证据与读取**：任务上下文、关联SI、原页及局部图像、原生表格与XLSX读取；同源唯一逐字引文可确定性恢复位置。原PDF和既有规范解析工件保持原样。

## 安装和入口

当前候选在源码目录安装，Python>=3.11：

```powershell
python -m pip install -e ".[ui,mcp]"
aletheia-nexus ui --library "D:\文献库"
```

GUI默认打开`http://127.0.0.1:8080`。普通CLI和解析不要求UI/MCP依赖，分别安装`.[ui]`、`.[mcp]`即可。浏览器运行时、Poppler及OCR仍按实际使用的可选路径安装，不把Python依赖已安装当作浏览器或OCR可用。

```powershell
aletheia-nexus research ask "整理方法、实验条件和主要结果，生成中文比较表并保留来源" --papers "D:\论文" --output-dir "D:\科研结果" --extraction-strategy source_first
aletheia-nexus mcp serve --allow-dir "D:\论文" --workspace "D:\科研结果"
```

密钥通过环境变量、GUI会话配置或显式Windows用户凭据提供，不写入任务、预设或普通日志。配置密钥不等于允许外发，MCP独立本机授权不能由模型参数代替。完整步骤见[工作台手册](WORKBENCH_USER_GUIDE.md)与[CLI/MCP指南](V08_ENTRYPOINTS.md)。

## 科学质量与边界

20篇ABC测试的两模型共同有效17篇中，DeepSeek严格字段查准/查全为71/84（84.52%），完整记录14/22；Qwen为69/84（82.14%）、12/22。另8篇B类确认中，正常先读后组装为21/24（87.5%）、5/8记录；这不是ABC整体准确率。所有评分为助手原文复核，**不是人类专家金标准**，GPT未改写运行答案。

残余问题包括条件/对象/阶段归属、必要信息遗漏、图中精确读数和误判源内冲突。完整字段与完整记录的严格分不等同于事实组覆盖或引用可定位率。界面、结构校验、测试通过均不能证明科学语义正确；关键结论仍需核对原文。完整实验、恢复与费用边界见[科研交付报告](V08_DELIVERY_REPORT.md)。

主要候选已做分级筛选，**不是每个变体都完成了充分的新论文泛化验证**。双模型自动选答、动态局部图像对最终完整记录的普适收益仍缺充分验证；步骤追加扩样没有适用缺口，也不能据此认定机制无效。队列关闭不等于路线被证明无效，未证实的能力不作为本版性能承诺。

出版社/SI覆盖仍受来源、权限、登录、验证码及文件状态影响；未发现附件不代表原文没有SI。文件备份和跨机历史路径修复不是一键完成；复杂步骤和完整引用编辑仍有专家入口。原0.7获取、解析和来源验证历史保持，不将旧成绩写成当前整合版重新实测。
