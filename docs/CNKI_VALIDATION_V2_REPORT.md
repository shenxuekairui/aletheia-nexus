# CNKI 验证与 AN 接入优化报告

日期：2026-10-09。实现与设计见 [CNKI 接入设计](CNKI_INTEGRATION_DESIGN.md)。本报告区分代码验证、真实浏览器 fixture 与机构网络实测，不将三者混为同一成功率。

## 完成的修改

- 共用身份验证 v2：修复真实 PDF 中全角字符、分隔符附近逐段换行、排版横线、j.cnki/j.issn 结构空格导致的 DOI 截断。保留普通 DOI 输入严格语法，阻止跨两个 DOI 或任意单词拼接。
- 首页 DOI 冲突保持硬边界；多重声明不以题名单独放行；增加无冒号独立 DOI 标签识别。参考区域和正文角色限制仍保留。
- AN 通用全文和浏览器获取溯源均新增验证 policy 与 declared_dois；已有 schema/键名兼容，不保存认证状态。
- CNKI 默认隔离保存可解析、已知 DOI 的未验证 PDF 和 sidecar，可用专用配置/CLI 开关关闭。保留状态不等于成功状态。
- 同一 BrowserAccessAttempt 优先返回 VERIFIED，其次返回题名证据最强的候选；顶层 evidence 保留具体拒绝依据，最后的错误候选不再掩盖目标文件。
- 注册路由支持发现结果中的真实 CNKI 域名，即使题名是英文；禁用开关有效，伪装域名不触发。调用顺序仍是本地显式文件优先、公开获取、适用官方 API、CNKI、其余浏览器回退。
- 明确同源 PDF 控件链接使用同认证上下文获取，不导航到内嵌预览器，不猜地址。订单 URL、权限、大小和 CAJ 拒绝保持已有边界，原生路径仍可显式选择。
- 初始搜索控件超时仅在无认证历史、无下载副作用时重开一次；认证期间不重载，已开始下载不自动重放。恢复失败增加异常类型，便于区分传输失败。

## 真实网络验收

固定新选跨领域 20 篇，输入题名 + DOI + 第一作者，正式 `acquire_cnki_pdf()` 与同一专用机构浏览器。此前旧 7 篇不参与此成功率。

- 修改前 14/20 VERIFIED，6 篇因 DOI 提取误判被拦截。
- 保存原始证据后，6 篇目标 PDF 在 v2 离线身份复核中全部 MATCH；第 2 篇额外错误候选依然 MISMATCH。
- v2 在线首轮 18/20 VERIFIED；首篇搜索控件超时，第 16 篇下载请求失败。
- 明确补测后第 1 篇恢复，累计 19/20 VERIFIED；19 份 PDF 的保存文件、sidecar、SHA-256 和最终代码身份判断均重新核对一致。
- 第 16 篇最后一次实测收到订单页需要原生下载的信号，但原生 PDF 获取超时，仍为 RETRIEVAL_FAILED。原始目标 PDF 离线身份正确不代表这次在线成功，未合并为 20/20。
- 收集诊断证据时人工完成一次 CAPTCHA；v2 在线重测无人工认证中断和浏览器崩溃。测试会话在结束后由测试进程释放；不修改日常浏览器。

逐篇结果与各次失败历史保存在本地 `aletheia-nexus-local-tests/cnki-multidiscipline-20-20261009/VALIDATION_V2_REPORT.md`；原始日志和全文不纳入 Git。

## 剩余限制

第 16 篇的订单页/原生下载超时仍需独立排查，现有证据不足以归因于 IP 没有权限或 browser crash。本轮已修复其身份误判，但未宣称解决这次在线传输问题。后续不能靠盲目重试或跳过验证提高成功率。

无真实 DOI 的标题-only 文献、只有 CAJ 的论文、OCR 识别和全机构订阅覆盖不是本次已完成能力。设计与代码已接入现有 AN 获取层，不另造身份体系；本次没有提交或推送，也没有改动机构凭据/系统网络配置。
