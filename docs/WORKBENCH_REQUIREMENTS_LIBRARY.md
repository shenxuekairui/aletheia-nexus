## 数据身份和长期复用（第十二部分）

| 关系或边界 | 状态与依据 |
| --- | --- |
| 论文、原始 PDF、来源、版本 | PDF 和来源哈希参与稳定 ID（`library.py:243`），不同声明不按 DOI 或文件名强行合并；原文件/来源不被可变名称污染 |
| 正文与 SI/其它附件 | 父身份、父 PDF 指纹、附件指纹和实际角色显式登记；同名规则只用于人读。普通导入拒绝把已知 SI 变成独立正文 |
| 解析版本、任务、执行和证据 | 解析新版本独立保存；执行固定材料快照；修订产生新结果，原页/证据引用仍绑定原身份。文件整理不改写科学记录 |
| 标签、分组、分类、集合、筛选、选择、视图 | 分别保存；物理分类移动与逻辑组织分开。全库标签修改同步分组/筛选，不改旧任务 |
| 缺失、异常和外部移动 | 保留旧身份及来源并显示诊断；不按文件名相似度重连。当前没有通用的任意外部路径修复向导，外部丢失的文件需恢复或明确重新定位核对 |
| 备份、导出与迁移 | 文库及工作区均为可复制的本地文件/JSON，使用手册说明完整备份边界；成果和证据有图形化导出。未建设一键整库备份/跨机器历史路径迁移工具 |
| 未来扩展 | 保持共享服务、稳定 ID 和版本接口；未引入语义数据库、知识图谱、ELN 或通用 Agent 以充当本轮功能 |

## 场景八、九、十与剩余范围

- **场景八：分类统一 SI**：已通过三合成正文/三 SI 及三篇真实 Nature Communications 正文、
  三个 PDF SI 和两个其它角色附件的 GUI 试验。覆盖不能推广为全部出版社；见最终验收记录。
- **场景九：中文批量重命名**：主文/SI 联动、中文模板、直接补译、逐篇覆盖、取消、冲突、迁移及回滚均已接线，
  3 篇真实论文通过 GUI 补译并实际改名，随后已有科研历史下单独迁移其中一篇通过 69 项独立检查；
  40 篇合成正文/SI 有规模回归。“几十篇真实英文论文全部经收费翻译后改名”尚未执行，不能夸称完成。
- **场景十：自定义文献视图**：列/宽度/顺序/排序/标题偏好持久保存；本轮补齐隐藏显示标题后仍有常驻多选控件。
  最终实际浏览器已验证隐藏标题列、拖动顺序/宽度、排序保存、重启恢复与 Shift 连续选择三篇；
  视图证据见最终验收记录，配置测试不替代浏览器记录。

确有价值但尚未提供的界面便捷项：已有论文的作者/年份/期刊专用批量编辑；集合、保存筛选和标签分组的
集中重命名/删除管理；任意外部路径的受控修复向导；一键完整备份；大型真实文库性能实测。
这些不应被当前后端的通用元数据/删除接口冒充已经接入 GUI。当前没有删除论文/PDF 的破坏性快捷功能。

本轮原需求回看已实际修复的主要遗漏是：隐藏标题后的多选、明确移回根目录、解析状态保存筛选、标签补全、
真实诊断列表、OCR/科研任务关联展示，以及命名视图的标题偏好。它们不是以“部分支持”标记代替实现。
