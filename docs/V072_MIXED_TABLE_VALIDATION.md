## 已完成的通用修复

部分嵌入式 CID 字体的字体级下降量与普通字符实际轮廓不符，原生文本框因此落在文字下方。中英文和数值被分成不同的行，随后 OCR 又在正确位置添加同一读法。现在读取嵌入字体的真实字形边界：只有多数映射到 ASCII 字母、数字的字形能证明正常文本框明显错位，才校正该字体的位置。按字体和 CID 区分字形，避免同一个 Unicode 数字的正文、上标和下标混用边界。这里调整坐标，不按论文内容猜数字或改单位。

表格发现支持“表头与两条数据行的列位置一致”的短表；换行单元格要求紧邻，防止远处页脚网址被吸入表格。相邻行恰好有相同数值时仍保留两行；原生与 OCR 真有不同读法时仍保留候选。

P19 p8 Table 4 从 **6 行、7 个列片段**恢复为 **3 行 × 4 列、12 个单元格**。三种电极分别对应：

| 指标 | 石墨粉/Nafion-铅 | L-石墨粉/Nafion-铅 | 石墨粉/PVP-铅 |
| --- | ---: | ---: | ---: |
| 平均电流密度 / mA·cm−2 | 45.67 | 45.09 | 45.62 |
| 耗电量 / C | 5261 | 5194 | 5255 |

六个结果数值各保留一次，负指数和表头对应保留，页脚不再进入表格。默认原生解析和双 OCR 路径都得到上述结构。表格仍是 `uncertain / not-interpreted` 的观测证据，未声称自动完成科学解释。

首个开发候选曾使 D05 的符号字体干扰主读法，也把 P19 页脚当作换行单元格，已在旧集回归中拒收。最终规则要求 ASCII 基线证据，不能用被错误映射成汉字的标点证明字体错位；同时限制实际换行距离。被拒候选及原因保留，没有覆盖失败记录。新增 13 个自编测试覆盖缩放、平移、CID 映射、同字不同上下标、相邻重复值、真实 OCR 冲突、短表和页脚；没有写入论文名称、DOI、答案数值或特定中文替换表。
