# 溯光（Aletheia Nexus）本地科研工作台使用手册

本功能位于开发分支，尚未正式发布。支持 Python 3.11 及以上，主要验收平台为 Windows。
科研抽取仍有图表关系、信息遗漏与条件归属局限；界面工程通过不等于科学准确率达标。

首次使用可从主页的“十分钟开始”按三步操作；[易用性改进与实测](WORKBENCH_USABILITY.md)
包含分组粘贴、混合目录/标签和首次入库→解析→检索→原页的实际记录。

## 安装与第一次打开

在本分支源码目录运行一次：

```powershell
python -m pip install -e ".[ui]"
aletheia-nexus ui --library "D:\文献库"
```

自动打开本机浏览器，默认地址 `http://127.0.0.1:8080`。后续可双击自行创建的启动快捷方式，
或复用同一命令。`.[ui]` 已包含 Playwright Python 依赖，不自动下载浏览器二进制。
默认尝试本机 Chrome/Edge 或已有 AN 运行时；缺少运行时、安全版本不兼容或配置错误时，按界面提示配置。
机构访问仍需有效的合法会话，登录与验证码由用户操作，不会被自动绕过。
附件下载地址可能另行要求登录或验证：正文已经能打开，不等于 SI 入口也已放行。
遇到此提示时保留 AN 可见浏览器中的论文页与附件验证页，按下文“仅补 SI”继续处理。
本地 OCR 需要 `.[ui,ocr]`、Poppler、Tesseract 与对应语言数据；RapidOCR 另按已有 image-ocr 说明配置。
原页图像也使用已有 Poppler；浏览器完整 PDF 和下载原文件是独立入口。

可通过 `--port 8098` 避开已有服务，通过 `--no-open` 保持后台。
`--workspace` 指定设置、任务、缓存、解析快照和成果保存目录；默认是启动目录下
`.aletheia-nexus/workbench/`。同一工作区只允许一个任务管理进程。
工作台仅绑定 `127.0.0.1`，没有公网/多用户模式。

已有 AN 文库可直接作为根目录，不强制迁移，也不需要重新下载。设置里可切换根目录；
有活动任务时先等待结束。切换后其他旧页面必须刷新，避免操作误落到另一文库。

首次需要模型时，打开“设置”顶部的“DeepSeek API 配置”，填写新密钥和官方接口基础地址，
点击“保存 API 配置”。密钥默认只用于本次进程；留空保留现有密钥，不会回显已有值。
Windows 可另行勾选保存到当前工作区的用户凭据管理器；其他平台仍用会话或环境变量，
也兼容 `DEEPSEEK_API_KEY`、`DEEPSEEK_BASE_URL`。预设、任务、日志和导出不保存密钥或 Cookie。
“检查连接（不发论文）”只查询模型列表，不保存新输入，也不生成科研内容。
有运行任务时先等待结束再改配置。已配置不等于认证、余额或模型权限已核实，
每次远程流程仍需单独授权；打开软件、浏览文库、解析和关键词检索不会默认调用模型。

新工作区使用下面的起步默认；已有显式保存的全局设置与命名预设不会被升级静默覆盖，
CLI 和 MCP 的原默认策略也不改变：

| 项目 | 新工作区默认 |
| --- | --- |
| 获取来源 | 公开来源先行；未成功时回退机构浏览器，不因环境中存在 API 密钥而自动启用官方接口 |
| 浏览器 | 可见、可交互，使用 AN 独立会话，自动选择可用运行时，跟随系统代理 |
| 人工登录与验证 | 不限时等待；正文等待期间默认自动复查，常用区可关闭；显式暂停仍需恢复，不自动解决验证码或越过权限 |
| 批量调度 | 普通论文间隔1秒；CNKI间隔和失败退避分别按原受支持参数执行 |
| SI 与解析 | 尝试 SI，成功正文和关联 PDF SI 自动进行原生文本优先解析；不强制覆盖旧版本 |
| 文件命名 | 年份-期刊-中文标题；缺中文译名时回退原题，可直接改为年份-期刊-原题或自己的模板 |
| OCR 与模型费用 | OCR关闭；入库标题翻译关闭；AI 整理、标题翻译和科研分析各自单独授权 |

检测到 Playwright 仅说明 Python 依赖存在，不等于浏览器已成功启动，更不代表具有机构或出版社权限。
公开来源成功时不必启动机构浏览器；遇到访问受阻仍按真实失败状态记录。

## 主页与软件内操作指南

启动后先进入“主页”。主页根据当前文库和真实任务记录，展示论文数、关联 SI 数、
解析覆盖、当前选择、近期任务及已保存成果；空文库会显示开始操作的入口，不填充演示文献。
可从主页直接进入获取、文库、检索和研究，也可打开右上角的选择清单、任务中心与设置。

点击“阅读操作指南”或顶部“操作指南”，无需联网即可查看首次使用、获取论文、文库整理、
解析检索、AI 研究、成果核对、任务恢复和设置说明。指南支持按“中文命名”“SI”“费用”
“恢复”等词查找操作。一般操作、参数名称、单位、状态和常见错误使用中文；
“原始诊断（专家）”保留必要的原始代码和脱敏详情，便于定位问题。

第一次使用建议先完成一篇论文的导入、打开原文、添加标签、解析与检索，再建立研究计划。
本地创建计划不调用模型；标题翻译、模型规划和科研执行分别确认实际外发范围及费用。

## 获取论文

1. 在“获取论文”粘贴 DOI、中英文标题，或选择 TXT/CSV/JSON 清单。可一次粘贴带分类分组的整批清单，再点“手动整理并预览”。
2. 检查输入错误、逐篇分类和标签；双击表中最终目录或标签打开本篇设置，勾选多行后点击“设置所选”批量整理，二者使用同一个窗口。也可展开高级列覆盖单篇基础文件名。核对最后实际启用获取的篇数。
3. 无 DOI 英文标题先“解析/确认标题”。只有唯一、精确且身份约束相符的候选自动通过；
   其余需要人工选择。中文标题保留 CNKI 书目路线，需适用权限与机构浏览器策略。
4. 填分类目录（新名称会安全创建）、标签、集合、命名模板；按需选择 SI 与自动解析。
   入库后自动标题翻译默认关闭；启用后仍需另行确认仅标题外发及本批费用上限。
5. 新工作区默认公开来源先行并允许机构浏览器回退；可改为仅公开获取。浏览器登录会话、人工处理策略、自动复查开关、等待时间、普通间隔、尝试次数和退避在常用区直接设置；
   请求/导航超时、CNKI 间隔、路线和候选预算、代理等放高级区。预设保存实际值，可修改复用。
6. 开始后直接查看本页获取进度、当前阶段、逐篇正文和 SI 独立状态。需要完整渠道、失败原因、目录、检查点和恢复记录时，打开“全部任务与历史”。

### 本页进度与登录处理

开始按钮下方直接显示真实任务进度，可从“查看获取任务”切换当前文库的已记录任务。
关闭、刷新或离开页面不取消后台获取；重新进入获取页可继续查看已保存的任务和逐篇结果。
进程退出后未完成任务会标为中断，必须审阅已有结果与检查点后再创建恢复任务，不会自动重新下载。

新工作区默认允许机构浏览器回退，使用 AN 独立的可见会话，不要求先打开浏览器或填写高级参数。
“检查本次浏览器配置”检查 Python 依赖、指定程序路径与可交互设置；它不启动登录，也不证明机构权限可用。
若改变高级浏览器配置，可再次点击检查；实际启动仍遵循已有运行时、安全版本与访问权限检查。
新工作区的默认浏览器会话为 `human-handoff`。已有工作区保存的会话（例如 `default`）会继续保留，
不会因升级静默切换；请以本次表单的“浏览器登录会话”为准。切换会话不会复制登录资料，可能需要重新完成合法登录。

需要登录或验证码时，在可见机构浏览器中操作。常用区“人工验证完成后自动检测并继续”默认开启，
仅在“等待人工登录 / 验证”模式的正文获取阶段生效；关闭后按“验证后继续”要求重新核查。
“立即重新检查”也只是触发检查，不代表验证已通过。选择暂停策略或主动暂停后，仍需手动恢复，
不会因页面已放行而自动解除。需要时可跳过或取消；0 秒表示不限时等待，正数是本次等待上限。
浏览器仍在等待时，继续接着当前尝试；如果该篇已经返回需要权限的结果，论文边界的继续只调度后续论文，
本篇需之后“选择失败论文重试 / 仅补 SI”。等待不是获取成功，不会自动绕过验证码、MFA或订阅限制。
暂停和取消在安全边界生效，已经开始的传输或已授权模型请求可能继续完成。

正文进度按论文请求计数；附件与解析按实际文件计数，一篇正文可能对应多个 SI。
“所有正文已验证”不表示整个任务已完成：请继续查看当前翻译、命名或解析阶段，等待最终状态。
逐篇流程在本篇正文及 SI 尝试结束后，按已选设置补译缺失标题、同步命名正文及附件、解析，再开始下一篇。
这些后处理失败会保留原因，不把已验证正文改为失败。
即使正文已经验证、解析覆盖全部物理页，解析仍可能因真实警告而显示“部分完成”，总任务也可能是“部分完成”。
请分别查看正文、SI、解析覆盖和警告，不要为清除总状态而重复下载已验证正文；页数覆盖也不代表科学提取准确率。

自动标题翻译共用**整批**费用与请求次数上限。逐篇即时翻译通常每个新标题至少需一次请求，重试也计入次数；
例如最多 20 次不能覆盖 25 个全新待译标题。缓存和已保护译名不需要新模型请求，软件不会静默加大预算。
费用未知时保留预留金额并阻止后续新翻译请求；已有缓存仍可用，命名可按原题回退，原文及已完成结果保留。

如果显示“正文成功，附件另需人工登录或验证”，请在保留的附件页完成操作，并保留该论文的正文文章页。
附件入口可能使用不同下载地址，因此不以正文已打开或此前已登录推断验证成功；软件也不会自动解决验证码。
本批结束后点击“选择失败论文重试 / 仅补 SI”→“仅补 SI”，选择刚才使用的浏览器会话，核对实际范围后确认。
此流程重新核验并复用已验证正文，保留其当前文件名，只尝试未完整取得的附件；权限拒绝或仍未放行时继续如实报告。
SI 阶段目前不会在人工处理后实时自动接着下载，须使用这个审阅后的补取入口。
自动 SI 的站点覆盖应以独立结果为准；正文能成功保存，也不保证该论文的 SI 自动获取成功。
真实复测中仍有 Wiley、RSC、Elsevier 官方页面要求人工操作、附件尚未取得的情况；
“未发现”也只代表本次未找到受支持入口，不证明论文没有 SI。必要时可从文献详情关联自己保存的本地附件。

### 文章页能打开，但 PDF 还没有保存

文章页面、正文 PDF 页面和 SI 下载页面可能分别要求登录或验证。完成文章页的验证后，
仍需查看新打开的 PDF 或附件页是否有自己的提示；不要因文章能阅读，就认定 PDF 传输或附件验证已经完成。
请保留当前 AN 浏览器会话中的文章页和相关 PDF/验证页，不要为了重试先关闭整组页面或整个浏览器。

“阅读器已响应，PDF 尚未交付”表示程序读到的是 PDF 阅读器页面，还没有取得可验证并保存的 PDF 文件。
它不是已下载成功，也不能单凭这个提示断言访问授权有问题。界面会保留原始诊断供排查；
只有文件取得并通过来源身份核验后，正文才显示“来源已验证”。

如果当前尝试仍在等待，请按所选的自动复查或手动继续方式处理；如果该篇已经以失败结束，
完成页面上的必要操作后，等本任务到达终态，再用下方入口只选择这一篇重试。
阅读器中的人工保存也不会自动变成已验证的获取结果；需要导入时按来源记录与本地导入规则处理。

### 重试未成功论文与补取 SI

任务结束后，在本页进度或任务中心点击“选择失败论文重试 / 仅补 SI”。窗口先核对当前文件、来源和检查点，
分别列出正文未成功、尚未开始、正文有效但 SI 待补、已完整完成，以及来源需先核对的项目。
默认只勾选可重试的未成功项。点击某行“只选这篇”会清掉其它勾选但不立即执行；
也可勾选几篇，或点击“仅补 SI”选出附件待补项，再核对数量、保存目录、原标签和会话，点击“开始重试所选论文 / 补 SI”。
只处理一篇时，先点该行“只选这篇”，确认“本次将重试 1 篇”；保留此前的文章/PDF 页面，并选择原先使用的浏览器会话。
选择一篇或几篇只改变本次范围，不会自动执行，也不会把未勾选的失败项一并重试。

正文已验证且检查点仍有效时，SI 补取沿用真实引擎的来源核验和正文复用，不重新下载正文。
正文改名或移动分类后，仍需按 PDF 与来源记录双哈希唯一定位，不能只按文件存在认定成功。
已经取得的附件由原 SI 服务核对后复用；未找到、部分失败或覆盖不完整仍如实记录。

可以在本次重试中改为“公开 + 机构浏览器”，其余超时、间隔、路线预算、逐篇目录、标签和文件名覆盖保留原值。
重试使用独立检查点，保留原检查点字节与原任务记录，并在当前获取页显示新任务。
付费标题翻译默认不重复开启；若确实需要重新启用，必须再次确认仅标题外发及费用上限。

原任务仍在运行时不能并行重试同一批。缺少原检查点或当前来源不能唯一核实时，旧成功项会标为需核对，
不会凭旧状态悄悄重新下载正文；先恢复原资料或在获取页明确建立新的请求。

### 任意文本的手动与模型规范化

可以先粘贴带编号、段落说明、分类标题或引用信息的清单，再整理成逐篇获取预览。
**整理输入、确认采用和开始获取是三个步骤**；整理不会下载论文，也不会自动创建分类目录。

不想使用模型时，点击“手动整理并预览”；需要时直接修改原文，把论文写为逐行 DOI 或完整标题，
用下文的分组标题、`分类=...` 和 `标签=...` 明确组织方式。手动预览不调用远程模型、不会计费。
本地规则只识别明确输入，不替用户推断科研分类；不规则引用或说明文字仍需检查它是否被正确识别为论文。

格式杂乱、需要模型协助拆分时，可使用“AI 整理输入”：

1. 检查要发送的粘贴文本、模型和本次费用上限；明确授权后才发出请求。这里只发送本次输入文字，
   不因为选择了文库就上传 PDF 或整个文库。模型规范化的授权不代替后续标题翻译或 AI 研究授权。
   长清单可点“使用大批量整理建议”，一次显示建议的输出容量与费用上限，再核对授权，无需先理解所有高级参数。
2. 在任务中心查看进度及实际返回的费用记录。页面关闭不代表请求已经撤销；费用未知时先核对，
   不把它当作零费用，也不要连续点击重试。
3. 核对逐篇 DOI、完整原题、原文对应位置、分类和标签。模型建议不能作为论文身份核验，
   不应把未提供的 DOI 当作已证实 DOI；仍需走已有的标题解析与正文来源验证流程。
4. 点击“确认采用并预览”后，结果进入现有获取预览。若等待期间又编辑了原文或当前草稿，先处理版本冲突，
   不用旧结果覆盖新输入；原始文本仍是核对依据。
5. 在逐篇预览中继续改分类、标签、是否获取等设置，核对启用篇数和重复冲突，最后单独点击开始获取。

右侧“本批多个目录”可为每个分组分别选择已有分类或新建子目录；“单篇目录与标签”可直接选择一篇调整。
表中目录和标签用于显示最终安排，双击后也进入同一个设置窗口，不需要在两套编辑方式之间重复输入。
批次默认目录只用于未单独指定的论文。主文与 SI 命名下拉包含“自定义模板”，也可直接修改实际模板、命名保存，
下次从列表复用。大批量结果的重复提示会合并计数，完整出处和调用账本在专家区域展开时加载。

原文明确的分组与模型建议的分类需要分别核对，不能把模型建议当作用户已经确认的目录。
采用预览后仍可选择已有分类或新建子目录，也可恢复继承默认。**根目录**表示明确不进入分类子目录，
**无标签**表示明确不给标签；两者都不是“留空后重新继承默认”。

同批不同论文可以分别进入不同分类。同一篇论文仍采用一个主存储位置；需要同时归入多个研究范围时，
使用多个标签或固定研究集合。不同目录的同篇候选会列为冲突，不会为了模型建议重复下载或复制多份正文。

模型请求失败不自动开始获取；已经收到结果但采用失败时，先在本地修正或重新选择已有预览，
避免把本地整理问题变成重复付费请求。程序接入见[规范化本地接口说明](WORKBENCH_NORMALIZATION_API.md)。

### 一批论文分别保存到不同分类

已经分好 A–D 四组、共 25 篇的清单可以整段粘贴；分组标题不计为论文，编号 DOI 不会当作无 DOI 标题。
分组只读取明确填写的目录与标签，不调用 AI，也不根据论文内容推断分类。先预览确认实际得到 25 篇，
再检查各组的分类、标签和重复提示，最后开始获取。

以下仅为输入格式示例，DOI 是占位符，不对应可供下载的真实论文；使用时换成自己的 DOI：

```text
A. 电合成/羧酸还原 | 标签=待读,羧酸
1. 10.1234/example-a01
2. 10.1234/example-a02

B. 电合成/醇氧化
标签=待读,醇
3. 10.1234/example-b01

C. 表征方法
4. 10.1234/example-c01 | 标签=方法参考

D. 待整理
5. 10.1234/example-d01 | 分类=/ | 标签=[]
```

每组下的论文继承该组设置；某行明确填写的设置覆盖该组对应字段；没有组设置的字段再继承右侧表单默认值。
上例最后一篇明确保存到文库根目录、不给标签。它不会因为默认分类或默认标签有内容而重新继承。

还支持以下明确格式：

- 方括号分类，例如 `[电合成/羧酸还原]`；组标题可附 `| 标签=待读,羧酸`。
- Markdown 层级，例如 `## 电合成` 后接 `### 羧酸还原`，得到相对目录 `电合成/羧酸还原`。
- 不使用分组，逐行填写 `DOI | 分类=电合成/羧酸还原 | 标签=待读,羧酸`。字段之间也可使用制表符。

`分类=/` 或 `分类=根目录` 表示明确放在文库根目录。`标签=`（等号后留空）、`标签=空`、`标签=[]` 或 `标签=无标签`
均表示明确不给标签；整个字段省略才表示继承。`分类=` 后不能留空，继承分类时省略该字段。
行内标签替换组标签。目录始终是当前文库内的相对目录，
不能用绝对路径或 `../` 越出文库。语法或目录错误会显示行号，错误分组不会偷偷沿用前一组。

### 预览后多选、批量修改

在预览中选中要整理的行，再应用分类或标签操作。编辑范围和获取范围分别显示：

- **选中行**决定本次批量编辑哪些论文，不自动改变是否获取。
- **获取状态**决定开始时提交哪些论文；用“启用选中论文 / 停用选中论文”修改。未选中但仍启用的论文也会获取。

分类可保持逐篇设置、恢复继承默认、统一指定相对分类，或明确放到根目录。标签可保持设置、恢复继承默认、
替换、追加、移除或清空。追加和移除以各篇当前实际标签为基础，保留逐篇差异；应用后该行成为独立覆盖，
后续默认标签变化不会再改动它。希望继续跟随默认时，选择继承默认。

| 意图 | 应采用的设置 | 之后修改表单默认值 |
| --- | --- | --- |
| 跟随本批默认分类或标签 | 继承默认 | 对仍继承的行生效 |
| 保留某篇独立分类或标签 | 逐篇覆盖 / 指定值 | 不改变这篇的覆盖 |
| 放到文库根目录 | 明确选择根目录 | 不恢复默认分类 |
| 本篇不给标签 | 明确清空标签 | 不恢复默认标签 |
| 此次批量操作不改这个字段 | 保持逐篇设置 | 保留原来的继承或覆盖方式 |

空白输入不应被当作同时表达“继承”与“清空”。需要根目录或无标签时，使用明确操作，并以预览中的实际分类和标签为准。
DOI、标题和高级列中的单篇文件名可直接编辑；目录和标签统一通过本篇或所选论文的设置窗口修改。
编辑单元格后可直接点击批量操作或开始按钮；界面先提交正在编辑的值，再读取本批参数。

同一身份且设置完全相同的重复输入会提示后去重；同一 DOI 出现在不同分类或具有不同标签时会明确列为冲突，
不会静默选第一项、合并标签或下载两份。请保留正确设置、停用重复行，再核对启用篇数。
预览后编辑 DOI、确认标题候选也可能引入新的重复，开始前仍会检查。输入去重不代替已存在文件的来源核验。

### 查看已有分类与新建子目录

获取页面的默认分类、批量分类及单篇分类设置可打开“选已有目录 / 新建子目录”。导入本地 PDF 时也可用同一选择器。
目录树包括已有空分类，可搜索目录名称、进入子目录或选择上一级；同时显示相对路径和完整保存路径。

使用已有分类时，选中目录后点击“使用选中目录”。新建时先选已有父目录，填写一级子目录名称，核对“新建后路径”，
再点击“新建子目录并使用”。打开选择器和填写文字都不会自动创建目录；同名文件不会被覆盖，已有同名目录直接选择即可。
文库根目录是明确选项，传回空相对路径；不会被显示成一层额外目录。

目录树只列举当前授权文库内的目录，不读取 PDF 内容；`SI/`、`json/`、内部数据目录、符号链接和 Windows 目录联接不会当作分类。
默认最多显示 1000 个目录（含根目录）、检查 24 层和 20000 个目录项，达到上限会说明列表尚不完整。
目录很多时，可直接填写已有相对路径并校验使用；搜索只针对本次已加载目录，不表示查遍了未加载部分。

标题解析成功不等于 PDF 已获取。只有原可信引擎验证成功的正文显示“来源已验证”。
自动 SI 支持 DOI 一致的官方页面明确附件链接；PDF SI 保存为明确父文关联的“人工声明身份”，
不冒充正文核验。SI 失败不会使已验证正文变为失败。具体覆盖见
[获取与 SI 支持说明](WORKBENCH_ACQUISITION.md)。

同一分类正文平铺，附件共享一个 SI 目录：

```text
文献库/羧酸还原/
  2026-期刊-论文甲.pdf
  2025-期刊-论文乙.pdf
  SI/
    2026-期刊-论文甲__SI-01.pdf
    2026-期刊-论文甲__SI-02.xlsx
    2025-期刊-论文乙__SI-01.pdf
  json/ ...原始来源与独立标签记录...
```

文件名不是关联依据；主文和 SI 通过父身份及哈希关联。不同分类各有自己的 SI/。
研究报告摘要、源数据、同行评议文件和真正 SI 分开登记。

## 整理文库与批量中文命名

“文献库”支持导入本地 PDF/文件夹、选择已有根目录、原题/中文译名/显示名/DOI/文件名检索、
分类/标签 AND 或 OR/固定集合/未翻译筛选。双击文献查看元数据、附件、来源和 PDF。
解析状态可筛选完成、部分、失败或尚未解析，并随保存筛选规则一起恢复。
展开列表下方的“来源、缺失文件与重复副本诊断”可查看实际异常路径和原因，不需要去终端查找。

同 DOI、同 PDF 指纹且都为自动核验正文的多条来源，默认显示为一行论文；不同 PDF 版本和本地声明来源不会因此合并。
原始来源 ID、文件、解析版本和各自 SI 都保留，双击可查看每份来源，或切换“按来源逐条查看”。
目录、标签和集合先筛选原来源，再归并显示；勾选一行只包含本次明确匹配的来源，不会悄悄加进未选的其他副本。
新解析、本地计划或远程规划若同时选中了同组多份来源，会请你选本次实际使用的一份，并显示路径、作者、解析状态和附件。
仅选一份或普通不同论文不增加确认步骤；取消不创建任务或产生模型调用，原选择清单和历史任务不变。

表头勾选或“全选当前页面”仅选中当前页；“加入全部筛选结果”操作全部筛选论文，显示真实篇数。
“加入选择清单”将已勾选文献加入全局清单，可跨页面积累、去重、移除、保存集合、解析或进入研究。
“解析已勾选”“检索已勾选”可直接处理当前表格勾选的论文，不改动已有跨页面选择清单；界面分别显示这两个范围的数量。
搜索输入可按回车应用，清除筛选后可重新查看全部文库；资料改变后使用刷新 / 应用筛选更新列表。
选择论文并不意味着所有附件自动上传；AI 执行前须确认主文/SI 范围。

五个概念分别保存：原始书目标题、模型/人工中文译名、自定义显示名、物理文件名、分类目录。
编辑显示名不等于磁盘改名。标签是可变元数据，集合保存明确成员，保存筛选保存条件，视图保存显示方式。
修改集合或标签不会改变历史研究输入。

### 直接补中文标题

在文库左侧勾选一篇或多篇论文，点击工具栏“补中文标题”，无需打开批量改名窗口。
可先勾选“未翻译”筛选，找出尚无中文译名的论文。文献详情也有同名入口。

- 单篇打开后可直接在“手动填写 / 修改（不联网）”输入中文标题，核对后保存；多篇时也可在该区选择一篇逐项补充。
- 批量默认“仅补缺失中文标题，已有译名保持”。查看本次处理、缓存复用和待外发数量；已有人工编辑或确认的译名始终保留。
- 需要模型时，核对模型、请求和费用上限，仅授权本次原题外发后点击“开始补中文标题 / 复用缓存”。PDF、正文和整个文库不外发；全部可复用缓存时无需付费请求授权。
- 参数可保存为标题翻译预设；载入预设或改变处理范围后，外发授权须重新确认。模型、超时、间隔和重译缓存选项放在高级区。

本窗口显示翻译任务状态，也可打开任务中心查看逐篇结果、缓存和费用记录。关窗不会取消已提交任务；
失败或费用未知时先查看原因，不连续点击重试。排队或请求期间人工补充的译名受保护，不会被模型返回值覆盖。
保存标题后文库更新显示；原题、文献身份、PDF 字节和物理文件名保持独立。
希望用译名命名磁盘文件时，再到“整理已勾选文献”预览并执行真实文件操作。

新工作区的获取命名默认“年份-期刊-中文标题”，缺少中文译名时使用原题，不会默认发起付费翻译。
命名下拉提供“年份-期刊-原题”，也可编辑实际模板并命名保存；已有全局偏好不会被静默覆盖。
命名时只在呈现层去掉成对的 `<sup>`、`<sub>` 等已知排版标签并解码实体，例如 `Ti<sup>3+</sup>` 生成 `Ti3+`，
期刊中的 `&amp;` 生成 `&`；标签内科学文本保留，数学比较内容不被泛删。
这不修改原题、人工译名或翻译缓存，不触发重译，也不自动整理已有文件；已有名称须自行预览并执行改名。

### 导入已有资料与手工关联 SI

普通 PDF 可在上传区域点击加号选择，或直接拖入。整批文件夹点击“从电脑选择文件夹”，
在图形选择器中选择磁盘/常用位置，进入目标文件夹后选择当前文件夹；无需手抄路径。
选择后会回填来源并展开“已选文件夹与路径”，检查是否包含子目录，再点“开始导入”。
也可展开该区域粘贴本地 PDF/文件夹的完整绝对路径；“开始导入”执行导入，不会打开选择窗口。
空路径时按钮不可用。Windows 复制路径时附带的成对引号可以保留；若 PDF 位于子文件夹，勾选“包含子目录中的 PDF”。
路径不存在、非 PDF、目录顶层没有 PDF 与包含子目录后仍没有 PDF 会分别提示，不会把空路径当作程序目录。

已有 AN 文库可以直接选为根目录。从带有来源 JSON 的本地路径将 PDF 导入当前文库时，系统保留原文件，
已有有效来源记录会按原字节复制，保留“来源已验证”或“人工声明身份”，不会重新声明身份。
通过浏览器只上传单个 PDF 时，无法同时读取它原来旁边的来源 JSON，因此按人工声明身份导入；
需要保留已有 AN 核验记录时，请直接打开原文库，或从带来源记录的本地路径导入。
原题以来源记录为准；导入时填写不同标题会给出提示，不覆盖原始书目。重复身份复用已有论文。
没有来源记录的 PDF 才按用户提供的标题和 DOI 登记为人工声明的本地文献。

已有 SI 按下面的流程关联：

1. 双击所属正文，展开“添加本地 SI / 其它关联附件”。
2. 输入附件绝对路径，或选择本地文件上传；确认当前显示的正文确实是它的所属论文。
3. 选择真实角色：SI、源数据、研究报告摘要、同行评审材料或其它附件。可补充附件标题。
4. 点击“登记到当前论文”，在任务中心查看结果，再刷新详情检查关联。

附件副本保存到该正文分类唯一的 `SI/`，使用正文实际基础名称及连续附件序号；扩展名保留。
同一附件的重复导入会复用已核验的记录。PDF SI 可随后与正文一起解析、检索和选择研究材料；
其它角色及非 PDF 附件只作安全保存登记，不承诺解析或自动打开。
当前本地附件上限为 200 MiB，只接受受支持的文档、数据、图片和媒体类型；不会执行附件或展开压缩包。

已知 SI 不能通过普通 PDF/文件夹导入被转换成独立正文。其来源若已声明其它所属论文，
工作台会拒绝重新归属并解释原因。请选择正确正文，不能通过改文件名或覆盖来源记录修复关联。
因此，递归导入混合正文和 SI 的旧文件夹时，正文可成功导入，已知 SI 会单独列出原因，
再从对应正文详情关联；“部分完成”不应被理解为所有文件均已入库。

### 标签、分组与全库修改

从“标签与分组”可对当前选择清单添加、移除自由标签，也可维护可选分组。
添加标签时输入文字会提示现有标签；回车可新建标签，支持多选，并保留逗号批量输入的兼容方式。
“全库标签重命名 / 删除”作用于当前文库的全部相关论文，同时更新分组和保存筛选中的标签条件。
重命名可合并到已有标签；删除不会改动原始 PDF、不可变来源、固定集合或历史科研任务快照。

执行前核对这是当前选择操作还是全库操作。删除保存筛选所用的标签会减少筛选限制，
可能扩大后续匹配范围；修改后请重新查看该筛选结果，再建立新的研究材料清单。

### 管理固定集合、保存筛选和标签分组

文库工具栏“管理集合 / 筛选 / 分组”集中维护这些对象；三者各自决定成员、筛选条件和标签组织。
选择一个固定集合，可用本次表格勾选或全局选择清单替换、追加、移除成员。
先预览原数量、新数量与具体新增/移除论文，再勾选确认执行；没有选中文献时不能凭空改变成员。
集合改名会同步更新保存筛选中的集合引用；被保存筛选引用的集合不能直接删除，界面会列出引用名称。
先调整相关筛选，再重新预览删除。过期预览需重做，不覆盖其他操作后的新状态。

保存筛选可更新为当前文库条件或直接运行；标签分组可修改组内标签，改组不会修改论文标签。
这些操作不改物理 PDF、来源或旧科研任务。若要调整已有研究范围，基于新集合明确建立新任务。

在“整理已勾选文献”或选择清单进入批量整理：

1. 选择模板，支持 `{year}`、`{journal}`、`{first_author}`、`{title_original}`、`{title_zh}`、`{custom_name}`。
   分类目标明确分为保持当前分类、移动到指定分类、移到文库根目录；移回根目录时附件进入根目录的共享 `SI/`。
2. 缺中文译名时可在本流程选择调用 DeepSeek 补齐、跳过或回退原题。查看缓存/人工译名与预算，
   只有勾选标题外发和费用授权后才调用。未确认的人工编辑也受保护，批量模型不会覆盖它。
   翻译参数预设可直接载入实际表单；载入后需重新确认本次外发和预算，强制重译不会自动沿用。
3. 生成完整主文和每个附件预览；检查旧/新路径、分类共享 SI 路径、译名来源、缺字段、冲突和可执行数量。
4. 可逐篇修改最终基础名或取消；修改后重新生成预检，核对后执行真实文件事务。
5. 在任务中心查看结果及文件操作日志；中断或失败时按日志做验证回滚，不手工移动隐藏中转文件。

源证据与旧解析工件字节不变。新研究材料采用独立快照，支持改名后继续旧任务。
已知历史契约/旧 CLI 检查点若无法安全重新定位，会拒绝该项并显示风险文件；不会静默重写。
工作台获取检查点支持哈希绑定的副本重定位。授权目录外的任意历史引用不可能自动发现。
文件事务当前限定单一文库根与支持硬链接的文件系统，跨卷不支持；异常会回滚或明确要求恢复。
长路径超过便携阈值 240 字符会被阻止，非法字符和过长基础名会在预览中说明规范化。

## 表格视图

内置标准文献、文件整理、获取管理、科研处理视图。通过“列/排序/视图”选显示列并另存名称；
表头拖动调整顺序和宽度，点击表头排序，变化自动持久保存。标题列可固定，长标题可换行。
设置中可选择中英文双行、中文优先、原题优先、自定义短名优先。
自定义视图也保存自己的标题显示偏好；未保存该偏好的旧视图才使用全局默认。
选择复选框固定在独立列，即使只显示原题和译名、隐藏“显示标题”，仍能进行多选。
元数据缺失显示空白，不自动编造作者、年份、期刊缩写或解析准确率。
“文件完整性”表示文件指纹是否一致，“来源身份”区分本地声明和可信获取验证；两者不能混同。
OCR 状态分别显示未启用、已配置待核对及实际使用，科研任务列只显示已有真实关联记录。

## 解析、检索与证据

从筛选结果、固定集合或当前选择清单批量解析。可复用可信旧工件，或明确创建新的解析版本；
旧版不覆盖。可设置原生文本/OCR、语言、DPI、页数/文本块和资源上限、段落合并等。
“解析完成”“部分解析”“解析失败”、页覆盖、警告、错误、解析器版本与来源检查分别展示。

“科研检索”选择范围、分类/标签、正文/SI、章节、AND/OR 或精确短语。证据视图显示段落/表格/图注，
论文视图按当前证据页归并。覆盖和总命中数始终保留；分页显示不能当作全部相关论文。
同论文多来源行保留本页全部实际命中来源及其证据；证据视图和导出保留逐条原始命中，不以显示归并代替材料身份。
材料核验数量包含所选范围中的正文与 SI，不等于来源角色筛选后参与命中的文件数。
切换论文/证据视图会清空本页旧勾选，请重新选择；切离再返回保留本客户端条件，点击检索重新运行。
未命中不表示论文未报道，标题译名命中也不等于中文正文语义检索。
勾选命中可加入选择、进入研究、导出原文证据，或直接打开相应 PDF 物理页。

## AI 研究、成果与修订

选择论文后，在“AI 研究”输入自然语言目标。可先生成本地计划（零 AI 调用），或明确授权
DeepSeek 规划目标与元数据；正文发送与规划授权分开。
执行前编辑实际材料、字段/类型、任务类型、步骤、比较、文本/选页图像模式、模型、Token/图片/
调用次数/费用预算。专家区可查看完整契约，但普通流程不要求填写 JSON 文件路径。

新建普通UI任务默认使用已验证有净收益的“先读后组装”；仍可选择“单轮直接提取”，两者复用同一科研引擎。
加载已有任务时保留其明确策略；旧任务省略策略时继续按单轮直接提取，不随新任务默认值迁移。
标准先读后组装每篇通常至少需要两次模型请求，跨篇比较、补页和重试另计；缓存可减少新调用。
请选择足够的调用与费用预算，程序不会替用户提高上限。策略会随任务和预设保存，加载旧任务时保留原选择；
变更策略后重新预览、核对范围和授权。已退役的逐字段独立读不会作为普通选项或被静默替换执行。
默认策略不会打开远程权限；本地准备模式仍为零模型调用，规划元数据和发送正文的授权继续分开。

实际输入固定为 PDF、来源和解析版本快照。计划修改后重新验证，并按本次范围勾选正文远程授权。
模型可能返回材料不足、缺 SI、部分结果或失败；它们是实际状态，不代表科学完整性。
默认不自动重发收费失败；计费不明保留预算预留，人工核对后再用历史契约创建恢复任务。

“研究成果”左侧结构化字段/主张/步骤与诊断，右侧 PDF 证据。选择数据并“核对证据”定位物理页，
SI 页码独立。原页图像与区域放大用于核对，完整 PDF 可单独打开。
“人工修订/确认”编辑值与适用条件、填写作者与理由，保存新版本；原结果保留。
自动化助手参与修改时选择“AI 辅助修订”，该模式禁止人工确认，不调用模型，也不把辅助核对记录成专家确认。
复杂引用和实验步骤的完整结构替换仍使用专家编辑区；普通值、原文值、单位、状态和条件无需手改 JSON。
人工确认是独立显式选项，不能因为引用可定位或模型输出通过契约格式检查就自动勾选。
支持 Markdown、CSV、JSONL 与必要任务/版本信息导出，并可沿用历史范围创建新任务。
每次导出还提供含原生结果、任务、材料清单、修订历史和哈希清单的 ZIP；ZIP 不包含全部原 PDF，
完整备份仍须同时保存文库与工作区。离线导出和阅读已有结果不会重复调用模型。

## 统一任务中心与设置

关闭/刷新页面不取消后台任务。暂停请求会等当前不可分操作结束；只有到达安全边界才显示“已暂停”。
取消同样等待安全边界；已发出的 HTTP/模型请求可能已发生或已计费，不能当作被撤销。
需要机构登录/验证时，可明确继续、跳过当前项或取消；不自动操作 CAPTCHA/MFA/订阅限制。
进程退出后未完成任务标记“已中断”，保留已完成项和检查点，不自行重跑。
文件事务日志同时记录已恢复、待恢复及冲突原因。重命名预览会后台扫描历史引用；
这不是文件已经移动，只有确认执行后才提交真正的磁盘事务，完成结果和恢复记录可在任务中心重看。

一般错误会给出中文原因和下一步建议。文件占用、名称冲突、历史引用风险或费用未知应分别处理，
不要连续点击执行来试探。未识别的新错误仍会保留脱敏的“原始诊断（专家）”；
记录缺失、来源不一致和预算不足不会被显示为成功。

常用设置放在任务表单；超时/OCR/预算等放高级折叠区；低层参数和完整契约放专家区。
全局默认、可命名预设和本次临时覆盖分别保存。预设只是参数组合，不保存密钥或 Cookie。
设置中诊断 Python、浏览器、Poppler/OCR 和 API 环境；缺依赖会给出实际错误，不显示假成功。
普通诊断表列出组件、实际状态、用途和下一步；原始详情可在专家区展开。
API 配置入口仅显示已有密钥是否存在及其来源，不回显密钥；检测到 Playwright 或密钥不代表浏览器、机构权限或模型请求已测试成功。
